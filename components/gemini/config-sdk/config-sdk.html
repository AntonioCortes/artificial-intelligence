Antigravity Python SDK (google-antigravity) y Sidecars

1. Antigravity Python SDK: Cómo programar y controlar Agentes desde Python

¿Sabías que no solo puedes hablar con el agente desde la ventana de chat o la terminal, sino que también puedes invocar y controlar programáticamente al agente de Antigravity desde tus propios scripts en Python? Google ofrece el paquete oficial google-antigravity (disponible en PyPI y en github.com/google-antigravity/antigravity-sdk-python) para que puedas integrar agentes autónomos dentro de tus herramientas DevOps, pipelines CI/CD o backends:


# Instalación del SDK oficial de Python de Google Antigravity
pip install google-antigravity
Instalación del paquete oficial google-antigravity desde PyPI.

1.1. Ejemplo completo: Lanzar un Agente, leer sus pensamientos y exponer herramientas propias

Con la API moderna basada en async with Agent(config) as agent:, puedes incluso pasarle funciones normales de Python decoradas o tipadas dentro de tools=[...] para que el agente las utilice automáticamente como herramientas MCP en memoria:


import asyncio
import sys
from google.antigravity import Agent, LocalAgentConfig, CapabilitiesConfig

# Puedes definir cualquier función de Python con type-hints y docstring
# para que el agente de Antigravity la use como herramienta propia:
def consultar_estado_contenedor(nombre_servicio: str) -> str:
    """Consulta el estado de salud de un contenedor Docker del entorno."""
    return f"El contenedor {nombre_servicio} está saludable (healthy) y usando 120MB de RAM."

async def main():
    # Por defecto el agente arranca en modo solo-lectura por seguridad.
    # Pasamos CapabilitiesConfig() para habilitar herramientas y añadimos nuestra función.
    config = LocalAgentConfig(
        system_instructions="Eres un ingeniero DevOps y Full Stack experto.",
        capabilities=CapabilitiesConfig(),
        tools=[consultar_estado_contenedor],
    )

    async with Agent(config) as agent:
        response = await agent.chat("Comprueba cómo está el contenedor api-backend y resume README.md")

        # 1. Escuchar los pensamientos internos (Thinking) en tiempo real:
        async for thought in response.thoughts:
            print(f"[Pensando] {thought}")

        # 2. Escuchar las llamadas a herramientas en tiempo real:
        async for call in response.tool_calls:
            print(f"[Herramienta] {call.name} -> {call.args}")

        # 3. Imprimir la respuesta final token a token:
        async for token in response:
            sys.stdout.write(token)
            sys.stdout.flush()

if __name__ == "__main__":
    asyncio.run(main())

2. ¿Qué son los Custom Sidecars en Antigravity?

En entornos empresariales o proyectos complejos de infraestructura, a veces necesitas que un proceso auxiliar (llamado Sidecar) arranque junto con el espacio de trabajo del agente y permanezca corriendo a su lado (por ejemplo, un proxy de autenticación corporativa, un túnel seguro hacia una base de datos en la nube o un demonio indexador en vivo).

Los Sidecars en Antigravity se configuran para acompañar el ciclo de vida de la sesión del agente, garantizando que los servicios locales auxiliares estén siempre levantados antes de que el agente o sus servidores MCP intenten conectarse a ellos.
