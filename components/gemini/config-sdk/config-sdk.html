Configuración Avanzada (skills.json, plugins.json) y Python SDK

1. Orden de Prioridad: ¿Qué pasa si hay varias Reglas o Skills con el mismo nombre?

A medida que empieces a personalizar Google Antigravity, es posible que tengas habilidades o reglas instaladas en tu ordenador personal (~/.gemini/config/) y otras distintas dentro de la carpeta de un proyecto del trabajo (.agents/). Antigravity las carga siguiendo un orden de prioridad estricto de mayor a menor (si dos Skills se llaman igual, gana la de número más alto):

  1. 1º Prioridad Máxima — Proyecto Actual (Workspace Discovery): Todo lo que esté dentro de la carpeta .agents/ (o .agent/, _agents/, _agent/) de tu proyecto actual subiendo hasta la raíz del repositorio Git.
  2. 2º Configuraciones Declaradas en el Proyecto: Las rutas explícitamente listadas en los archivos .agents/skills.json o .agents/plugins.json del repositorio.
  3. 3º Configuración Global de tu Máquina: Las personalizaciones guardadas en tu carpeta de usuario ~/.gemini/config/.
  4. 4º Personalizaciones Integradas (Built-in): Las habilidades que vienen de fábrica con Antigravity.
  5. 5º Configuraciones Globales Declaradas: Las listadas en archivos JSON globales.

2. Compartir Skills y Plugins en carpetas a medida (skills.json y plugins.json)

En muchos equipos o empresas, las habilidades compartidas no se guardan en .agents/skills/, sino en una carpeta corporativa común (por ejemplo, tools/ia/skills/ o una ruta compartida). Para indicarle a Antigravity que busque allí e incluso herede configuraciones filtrando cuáles incluir o excluir, puedes crear el archivo .agents/skills.json (o .agents/plugins.json):


{
  "inherits": [
    {
      "path": "/ruta/compartida/empresa/skills.json",
      "include_only": ["auditoria-seguridad", "estilo-corporativo"],
      "exclude": ["skill-antigua"]
    }
  ],
  "entries": [
    {
      "path": "tools/ia/skills",
      "exclude": ["experimental-.*"]
    },
    {
      "path": "~/mis-skills-personales"
    }
  ]
}

2.1. Activar, desactivar e importar Plugins desde el CLI

Además de crear plugins nativos de Antigravity, la herramienta de terminal agy permite activar o desactivar plugins (lo cual se guarda en tu config.json sin modificar los archivos del plugin) e incluso importar extensiones creadas para Gemini CLI o Claude Code:


# Activar o desactivar un plugin concreto desde la terminal
agy plugin enable mi-plugin-equipo
agy plugin disable mi-plugin-equipo

# Instalar o importar un plugin (incluyendo extensiones de Gemini CLI o Claude Code)
agy plugin install /ruta/al/plugin

3. Antigravity Python SDK: Cómo programar y controlar Agentes desde Python

¿Sabías que no solo puedes hablar con el agente desde la ventana de chat, sino que también puedes invocar y controlar al agente de Antigravity desde tus propios programas en Python? Google ofrece el paquete oficial google-antigravity (disponible en PyPI) para que puedas automatizar agentes dentro de tus scripts, tests o flujos de integración continua:


import asyncio
import sys
from google.antigravity import Agent, LocalAgentConfig, CapabilitiesConfig

async def main():
    # Por defecto el agente arranca en modo solo-lectura por seguridad.
    # Pasamos CapabilitiesConfig() para habilitar herramientas de escritura y terminal.
    config = LocalAgentConfig(
        system_instructions="Eres un asistente experto en revisar proyectos web.",
        capabilities=CapabilitiesConfig(),
    )

    # Arrancamos el agente con el gestor de contexto asíncrono
    async with Agent(config) as agent:
        response = await agent.chat("Revisa README.md y resume cómo se crea una vista.")

        # Podemos escuchar los pensamientos internos (Thinking) en tiempo real:
        async for thought in response.thoughts:
            print(f"[Pensando] {thought}")

        # Y podemos escuchar las herramientas que ejecuta:
        async for call in response.tool_calls:
            print(f"[Herramienta] {call.name} -> {call.args}")

        # Finalmente mostramos la respuesta token a token:
        async for token in response:
            sys.stdout.write(token)
            sys.stdout.flush()

if __name__ == "__main__":
    asyncio.run(main())
