Modelos de Gemini y Plataforma Google Antigravity

1. ¿Qué es Gemini y qué es Google Antigravity (AGY)?

Es muy frecuente preguntarse por qué a veces oímos hablar de Gemini y otras veces de Antigravity (o AGY). La distinción es muy sencilla:

  • Google Gemini es la familia de modelos de Inteligencia Artificial (el "cerebro" creado por Google DeepMind que razona, entiende texto, imágenes y código).
  • Google Antigravity (AGY) es la plataforma de desarrollo agéntica (el "cuerpo y entorno de trabajo") donde ese cerebro de Gemini cobra vida para leer tus carpetas, ejecutar comandos en la terminal, usar herramientas MCP, gestionar subagentes y crear artefactos.

2. ¿Qué modelos de Gemini existen y cuál debo elegir?

Tanto en los ajustes de Antigravity como cuando se lanzan subagentes verás distintos niveles de modelos de Gemini. Cada uno está diseñado para un propósito diferente:

Modelo Velocidad Profundidad de Razonamiento Cuándo debes usarlo
Gemini Flash Lite (flash_lite) Instantánea Básica / Directa Para tareas muy sencillas, resúmenes rápidos, formateo de texto o subagentes que hacen búsquedas simples.
Gemini Flash (flash) Muy rápida Alta Excelente para el trabajo diario ágil: crear componentes sencillos, responder preguntas rápidas, buscar archivos o hacer ediciones puntuales sin esperar.
Gemini Pro / Thinking (pro) Moderada (piensa antes de actuar) Máxima (Razonamiento multicapa) Para diseñar arquitecturas complejas, depurar errores difíciles, planificar proyectos enteros o coordinar múltiples archivos y diagramas sin cometer fallos.

3. Las 3 Superficies de Google Antigravity: IDE, Desktop App y CLI

Puedes utilizar el mismo agente y las mismas personalizaciones (Skills, Reglas y MCP) desde tres programas distintos según cómo te guste trabajar:

3.1. Antigravity IDE (El editor de código con IA integrada)

Es un entorno de desarrollo completo (construido sobre la base de VS Code) pensado para cuando estás escribiendo o revisando código directamente. Ofrece tres modalidades de IA complementarias:

  1. Modalidad Pasiva — Antigravity Tab (Autocompletado y Supercomplete): Mientras escribes código, la IA predice tu siguiente intención. No solo completa la línea actual (Autocomplete), sino que muestra ventanas flotantes con cambios de varias líneas (Supercomplete), añade automáticamente los imports arriba del archivo cuando usas una librería nueva (Tab to Import) y predice a qué línea del archivo vas a querer saltar a continuación para llevarte allí pulsando simplemente Tab (Tab to Jump). Para aceptar pulsas Tab, para cancelar Esc, y para aceptar palabra por palabra Ctrl + Flecha Derecha (o Cmd + Flecha Derecha en Mac).
  2. Modalidad Instructiva — Edición Inline (Ctrl + I / Cmd + I): Si seleccionas unas líneas de código con el ratón y pulsas Ctrl + I, se abre una pequeña caja de texto justo encima del código. Puedes escribir "añade comentarios explicativos" o "convierte este bucle en un map" y la IA modificará únicamente el bloque seleccionado mostrando las diferencias en verde y rojo (Visual Diff Overlays).
  3. Modalidad Colaborativa — Sidebar Chat & Agent Mode: Es el panel lateral donde hablas con el agente para tareas de múltiples pasos que requieren leer varios archivos, usar la terminal o planificar toda una funcionalidad. Además, encima de tus funciones y clases verás botones rápidos (Inline Code Lenses) para explicar, refactorizar o crear tests con un clic, y botones de Diagnostic Auto-Fix para arreglar errores del compilador automáticamente.

3.2. Antigravity 2.0 (La aplicación de escritorio para dirigir agentes)

Es una aplicación de escritorio independiente diseñada para que gestiones uno o varios agentes trabajando en tus proyectos sin necesidad de tener un editor de código tradicional abierto. Su interfaz se divide en:

  • Barra lateral izquierda (Left-hand Sidebar): Desde donde inicias nuevas conversaciones (New Conversation), cambias de repositorio (Projects), programas tareas recurrentes o temporizadores (Scheduled Tasks), gestionas tus Skills & Customizations y configuras permisos globales o por proyecto (Settings).
  • Lienzo de Chat (Chat Canvas): El panel central donde conversas con el agente, usas comandos con /, mencionas archivos o herramientas con @ y arrastras imágenes o capturas de pantalla.
  • Panel Auxiliar (Auxiliary Pane): Donde puedes inspeccionar en tiempo real los Artefactos (planes de ejecución, informes con diagramas, tablas y carruseles generados por el agente), los Subagentes activos, las Tareas en segundo plano (Background Tasks), los Archivos modificados y las Terminales.

3.3. Antigravity CLI (agy) (El agente en tu terminal)

Si prefieres trabajar directamente desde la consola de comandos de Linux, macOS o Windows, la interfaz de línea de comandos agy te ofrece toda la potencia del agente de forma instantánea:


# 1. Iniciar el agente interactivo en la carpeta actual de tu proyecto
agy

# 2. Ver todas las opciones y subcomandos disponibles desde la terminal
agy --help

# 3. Dentro de la interfaz interactiva de agy:
#    - Escribe /help para ver todos los slash commands
#    - Pulsa Ctrl+D dos veces (o escribe /exit o /quit) para salir
