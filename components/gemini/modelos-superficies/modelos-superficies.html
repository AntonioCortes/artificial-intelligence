Superficies de Google Antigravity: IDE, Desktop App 2.0 y CLI (agy)

1. Las 3 Superficies donde puedes usar Google Antigravity

Una vez entendido que Gemini es el modelo (el cerebro), Google Antigravity (AGY) te permite trabajar con el mismo agente y las mismas personalizaciones (Reglas, Skills, Plugins y Servidores MCP) desde tres programas o superficies distintas según tu preferencia en cada momento:

  • 1. Antigravity IDE: El editor de código completo (basado en VS Code) con IA integrada en cada rincón.
  • 2. Antigravity 2.0 (Desktop App): La aplicación de escritorio dedicada a orquestar agentes, artefactos y tareas en paralelo.
  • 3. Antigravity CLI (agy): La herramienta ligera de terminal para desarrolladores y entornos DevOps/SSH.

2. Antigravity IDE (El editor de código con IA integrada)

Pensado para cuando estás programando o revisando código directamente. Ofrece tres modalidades de IA complementarias:

  1. Modalidad Pasiva — Antigravity Tab (Autocompletado y Supercomplete): Mientras escribes código, la IA predice tu siguiente intención. No solo completa la línea actual (Autocomplete), sino que muestra ventanas flotantes con cambios de varias líneas (Supercomplete), añade automáticamente los imports arriba del archivo cuando usas una librería nueva (Tab to Import) y predice a qué línea del archivo vas a querer saltar a continuación para llevarte allí pulsando simplemente Tab (Tab to Jump). Para aceptar pulsas Tab, para cancelar Esc, y para aceptar palabra por palabra Ctrl + Flecha Derecha (o Cmd + Flecha Derecha en Mac).
  2. Modalidad Instructiva — Edición Inline (Ctrl + I / Cmd + I): Si seleccionas unas líneas de código con el ratón y pulsas Ctrl + I, se abre una pequeña caja de texto justo encima del código. Puedes escribir "añade comentarios explicativos" o "convierte este bucle en un map" y la IA modificará únicamente el bloque seleccionado mostrando las diferencias en verde y rojo (Visual Diff Overlays).
  3. Modalidad Colaborativa — Sidebar Chat & Agent Mode: Es el panel lateral donde hablas con el agente para tareas de múltiples pasos que requieren leer varios archivos, usar la terminal o planificar toda una funcionalidad. Además, encima de tus funciones y clases verás botones rápidos (Inline Code Lenses) para explicar, refactorizar o crear tests con un clic, y botones de Diagnostic Auto-Fix para arreglar errores del compilador automáticamente.

3. Antigravity 2.0 (La aplicación de escritorio para dirigir agentes)

Es una aplicación de escritorio independiente diseñada para que gestiones uno o varios agentes trabajando en tus proyectos sin necesidad de tener un editor de código tradicional abierto. Su interfaz se divide en:

  • Barra lateral izquierda (Left-hand Sidebar): Desde donde inicias nuevas conversaciones (New Conversation), cambias de repositorio (Projects), programas tareas recurrentes o temporizadores (Scheduled Tasks), gestionas tus Skills & Customizations y configuras permisos globales o por proyecto (Settings).
  • Lienzo de Chat (Chat Canvas): El panel central donde conversas con el agente, usas comandos con /, mencionas archivos o herramientas con @ y arrastras imágenes o capturas de pantalla.
  • Panel Auxiliar (Auxiliary Pane): Donde puedes inspeccionar en tiempo real los Artefactos (planes de ejecución, informes con diagramas, tablas y carruseles generados por el agente), los Subagentes activos, las Tareas en segundo plano (Background Tasks), los Archivos modificados y las Terminales.

4. Antigravity CLI (agy): Todos sus Flags y Subcomandos de Terminal

Si prefieres trabajar directamente desde la consola de comandos de Linux, macOS o Windows, la interfaz de línea de comandos agy te ofrece toda la potencia del agente de forma instantánea:

Flag / Opción de agy Qué hace al arrancar desde la terminal
agy Inicia la interfaz interactiva (TUI) del agente en la carpeta actual.
agy -c (o --continue) Continúa automáticamente la conversación más reciente donde la dejaste.
agy --conversation <ID> Reanuda una conversación anterior específica indicando su identificador.
agy -i "tu prompt" (--prompt-interactive) Arranca la sesión interactiva enviando ya el primer mensaje automáticamente.
agy -p "tu prompt" (o --print) Modo No Interactivo (Print Mode): Ejecuta un único prompt, imprime la respuesta en la consola y termina (ideal para scripts y tuberías Unix).
agy --mode <modo> Define el modo de ejecución del agente para la sesión: plan (solo planificar), accept-edits (aceptar ediciones) o auto.
agy --model <modelo> Inicia la sesión utilizando directamente el modelo especificado.
agy --effort <nivel> Establece el nivel de esfuerzo de razonamiento inicial: low, medium, high, xhigh o max.
agy --add-dir <ruta> Añade una o varias carpetas adicionales al espacio de trabajo (se puede repetir).
agy --sandbox Fuerza la ejecución dentro del entorno Sandbox con restricciones de terminal activadas.
agy --output-format <formato> y --json-schema En modo -p, permite pedir la salida en formato text, json o stream-json, e incluso exigir que cumpla un esquema JSON concreto.
Tabla 1. Todas las banderas (flags) de línea de comandos soportadas por el binario agy.

4.1. Subcomandos de gestión directa (agy <subcomando>)


# 1. Listar todos los modelos o agentes disponibles
agy models
agy agents

# 2. Gestionar servidores MCP desde la consola (add, remove, list, enable, disable)
agy mcp list
agy mcp enable mi-servidor

# 3. Gestionar plugins (list, import, install, uninstall, enable, disable, validate)
agy plugin list
agy plugin import claude

# 4. Otros subcomandos útiles del sistema
agy changelog        # Ver novedades de la versión
agy install          # Configurar variables PATH del sistema
agy remote-control   # Gestionar el daemon de control remoto (start, status, stop)
agy update           # Actualizar Antigravity CLI a la última versión
Subcomandos administrativos disponibles directamente desde la terminal con agy.
