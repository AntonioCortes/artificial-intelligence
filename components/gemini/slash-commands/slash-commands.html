Comandos con / (Slash Commands) en Antigravity

1. ¿Qué ocurre cuando escribes / en el chat?

Cuando escribes una barra inclinada / al principio de tu mensaje en el chat de Google Antigravity (tanto en la aplicación de escritorio Antigravity 2.0, como en el IDE o en el CLI agy), se despliega el menú de Slash Commands (Comandos de Barra).

¿Qué es un Slash Command? Es un atajo directo que activa un modo especial de trabajo o un flujo automatizado en el agente. En lugar de tener que explicarle con un párrafo largo cómo quieres que se comporte (por ejemplo: "quiero que pienses muy a fondo, que primero me hagas preguntas o que lances varios agentes en equipo"), basta con elegir el comando con / correspondiente.

2. Catálogo completo de Comandos / para Flujos Agénticos

Estos son los comandos principales que verás al pulsar / en Antigravity, explicados al detalle con cuándo y por qué deberías usar cada uno:

Comando Qué hace exactamente Cuándo debes usarlo (Caso ideal)
/plan Activa el modo de planificación estructurada paso a paso antes de realizar cambios en el código. Cuando la tarea es grande o toca muchos archivos y quieres revisar primero la estrategia del agente antes de que empiece a editar.
/goal Modo de objetivo autónomo persistente: el agente es ultra exhaustivo y no se detiene hasta verificar que la meta se ha cumplido al 100%. Cuando quieres dejar al agente trabajando en una tarea larga (incluso durante horas) asegurándote de que no pare a mitad de camino.
/boost Activa pensamiento profundo estratégico, análisis desde múltiples perspectivas y verificación rigurosa. Cuando te enfrentas a un bug muy difícil de encontrar, un problema de arquitectura complejo o una investigación técnica profunda.
/grill-me Inicia una entrevista interactiva donde la IA te hace preguntas clave para resolver dudas de diseño antes de programar. Cuando tienes una idea general de lo que quieres hacer pero aún no has decidido todos los detalles técnicos y quieres que la IA te ayude a aterrizarlos.
/teamwork Orquesta un equipo de subagentes autónomos que se reparten el trabajo y colaboran en paralelo. Cuando tienes un proyecto grande con partes independientes (por ejemplo: crear 4 vistas distintas o migrar 20 módulos a la vez).
/browser Activa las capacidades de navegación web y automatización del navegador integrado. Cuando quieres que el agente abra tu página web en un navegador real para probar cómo se ve, hacer clic en botones o buscar información en la web.
/schedule Permite programar una instrucción en un temporizador único o en un horario recurrente (formato cron). Cuando quieres que el agente ejecute una revisión periódica (por ejemplo: comprobar cada mañana si los tests o el servidor siguen funcionando).
/compact Resume y compacta el historial de la conversación actual para liberar espacio en la ventana de contexto. Cuando llevas mucho rato trabajando en el mismo chat y quieres liberar memoria sin perder el resumen de lo que ya habéis hecho.
/learn Guarda una enseñanza, corrección o configuración compleja que hayáis resuelto para que el agente la recuerde en futuras sesiones. Cuando acabas de corregir al agente o de enseñarle cómo funciona tu proyecto y quieres que aprenda esa regla para siempre.

3. Ejemplos reales de cómo usar los comandos / paso a paso

Veamos cómo se escriben estos comandos en situaciones reales del día a día:


# Caso 1: Quieres diseñar una funcionalidad nueva pero tienes dudas -> Usa /grill-me
/grill-me Quiero añadir un sistema de buscador avanzado que filtre también dentro del
contenido HTML de cada componente y no solo en los títulos del sidebar.

# Caso 2: Quieres un plan detallado antes de tocar código -> Usa /plan
/plan Necesito migrar todos los componentes antiguos de @components/another-view/
al nuevo formato de WebComponents explicado en @README.md.

# Caso 3: Tienes un proyecto grande y quieres que varios agentes trabajen en equipo -> Usa /teamwork
/teamwork Crea tres vistas nuevas en paralelo: una para Docker, otra para Kubernetes
y otra para GitHub Actions, cada una con 5 componentes y sus diagramas SVG.

# Caso 4: Quieres que el agente no pare hasta dejar todo probado y terminado -> Usa /goal
/goal Revisa todos los componentes de la web, comprueba que todas las imágenes SVG existen,
que todos los componentes están en @js/components-imports.js y que no hay errores.

# Caso 5: Acabas de explicarle una norma importante y quieres que la memorice -> Usa /learn
/learn Recuerda siempre que en este repositorio nunca debemos usar etiquetas code de una
sola línea dentro de párrafos porque addCodeLineNumbers() espera bloques multilínea.

4. Comandos de control adicionales en Antigravity CLI (agy)

Cuando estás dentro de la terminal usando agy, además de los comandos anteriores dispones de comandos utilitarios para gestionar la sesión:

  • /help: Muestra en pantalla la lista completa y actualizada de todos los comandos de barra disponibles en tu versión del CLI.
  • /exit o /quit (o pulsar Ctrl + D dos veces): Cierra limpiamente la sesión interactiva del agente en la terminal.
