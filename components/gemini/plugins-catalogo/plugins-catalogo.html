Repositorios y Catálogo de Plugins para Antigravity (Full Stack y DevOps)

1. ¿Dónde ver el listado de Plugins y Extensiones disponibles para Antigravity?

Gracias a que Google Antigravity (agy) soporta tanto plugins nativos (plugin.json) como extensiones de Gemini CLI (gemini-extension.json) y plugins de Claude Code (.claude-plugin/plugin.json), tienes acceso a los cuatro mayores directorios de plugins de IA para desarrolladores:

Catálogo / Repositorio Oficial URL Directa Qué encontrarás y cómo instalarlo en Antigravity
1. Galería Oficial de Extensiones Gemini geminicli.com/extensions y github.com/google-gemini Catálogo oficial de Google Cloud, Firebase, Cloud Run, Kubernetes (GKE), bases de datos (PostgreSQL, MySQL, AlloyDB, Redis, Spanner, BigQuery), GitHub, Figma, Stripe y Sentry.
2. Directorio Oficial de Plugins de Anthropic (Compatible) github.com/anthropics/claude-plugins-official Contiene decenas de plugins oficiales (frontend-design, playwright, commit-commands, pr-review-toolkit, feature-dev, security-guidance, supabase) que puedes clonar e instalar con agy plugin install.
3. Mega-Catálogo de Plugins DevOps y Full Stack github.com/wshobson/agents y EveryInc/compound-engineering-plugin Más de 60 plugins especializados por áreas técnicas: arquitectura backend, Kubernetes, Terraform, CI/CD, seguridad DevSecOps, observabilidad y desarrollo web.
4. Repositorio Oficial de Servidores MCP github.com/modelcontextprotocol/servers Repositorio central de conectores MCP listos para integrar dentro del archivo mcp_config.json de tus plugins.
Tabla 1. Los 4 grandes catálogos y repositorios donde descargar plugins y extensiones para Antigravity. 

# Ejemplo: Clonar el repositorio oficial de plugins e instalar los que te interesen en Antigravity
git clone https://github.com/anthropics/claude-plugins-official.git /tmp/plugins-oficiales
agy plugin install /tmp/plugins-oficiales/plugins/frontend-design
agy plugin install /tmp/plugins-oficiales/plugins/commit-commands
agy plugin install /tmp/plugins-oficiales/plugins/security-guidance

# Comprobar que han quedado instalados y activos:
agy plugin list
Cómo instalar cualquier plugin del repositorio oficial en tu entorno de Google Antigravity con agy plugin install.

2. Catálogo Extenso de Plugins Interesantes para Desarrollador Full Stack

Plugin / Extensión Origen / Dónde conseguirlo Qué incluye y por qué es clave para un Full Stack
frontend-design anthropics/claude-plugins-official (plugins/frontend-design) Inyecta skills y reglas de diseño UI/UX, arquitectura CSS/Tailwind, componentes accesibles y patrones visuales modernos para HTML, React, Vue o Angular.
playwright anthropics/claude-plugins-official (external_plugins/playwright) Configura automáticamente el servidor MCP oficial de Playwright para que el agente abra un navegador real, pruebe tu web Full Stack, detecte errores en la consola JS y haga capturas.
feature-dev anthropics/claude-plugins-official (plugins/feature-dev) Flujo estructurado en 7 fases para desarrollar nuevas funcionalidades Full Stack de extremo a extremo (exploración del código, diseño de arquitectura, implementación y revisión).
postgres / cloud-sql-postgres Galería geminicli.com/extensions (google-gemini) Conector MCP de PostgreSQL + skills de optimización de consultas SQL, índices y migraciones seguras inspeccionando el esquema real de tus tablas.
supabase anthropics/claude-plugins-official (external_plugins/supabase) Conecta el agente con tus proyectos de Supabase (PostgreSQL, políticas Row Level Security, Auth, Edge Functions y generación automática de tipos TypeScript).
firebase Galería geminicli.com/extensions (Oficial de Google) Incluye servidor MCP y skills para Firestore, Firebase Auth, Hosting y Cloud Functions, validando reglas de seguridad antes de desplegar.
context7 anthropics/claude-plugins-official (external_plugins/context7) Inyecta documentación oficial actualizada en tiempo real de cualquier librería (Next.js, React, Tailwind, Astro, FastAPI, Prisma, Spring Boot) evitando código obsoleto.
stripe y figma anthropics/claude-plugins-official (external_plugins/) figma traduce diseños de Figma a componentes HTML/CSS/React; stripe automatiza la integración de pasarelas de pago, suscripciones y webhooks.

3. Catálogo Extenso de Plugins Interesantes para DevOps, Cloud, CI/CD y Seguridad

Plugin / Extensión Origen / Dónde conseguirlo Qué incluye y por qué te ahorra horas en DevOps
commit-commands y pr-review-toolkit anthropics/claude-plugins-official (plugins/) Automatiza commits semánticos, subida de ramas, creación de Pull Requests y revisión profunda del código antes de fusionar en main.
security-guidance anthropics/claude-plugins-official (plugins/security-guidance) Hook preventivo DevSecOps que vigila cada edición de archivos y alerta si detecta inyección de comandos, XSS, uso de eval() o vulnerabilidades en workflows de GitHub Actions.
github y gitlab anthropics/claude-plugins-official (external_plugins/) Conecta el agente con tus repositorios, Pull Requests, Merge Requests y logs de pipelines CI/CD fallidos en GitHub Actions o GitLab CI para diagnosticar y reparar fallos.
cloud-run y gke-kubernetes Galería geminicli.com/extensions (Oficial de Google Cloud) Permite desplegar contenedores serverless en Cloud Run o diagnosticar clústeres de Kubernetes (pods en CrashLoopBackOff, eventos, escalado HPA y manifiestos YAML).
cloudflare y vercel Galería geminicli.com/extensions y claude-plugins-official Gestión de despliegues en el Edge, Workers, DNS, cachés CDN, análisis de logs de funciones serverless y variables de entorno por proyecto.
terraform-infrastructure wshobson/agents y antonbabenko/terraform-skill Combina skills de Infraestructura como Código (Terraform / OpenTofu) con hooks que ejecutan automáticamente terraform fmt, terraform validate y tflint.
sentry y grafana-observability Galería geminicli.com/extensions y claude-plugins-official Conecta el agente con las alertas y trazas de error reales de producción en Sentry, Prometheus y Grafana para localizar el archivo causante del incidente y generar el parche.
