Dónde Conseguir Skills: Mejores Repositorios y Catálogo para Full Stack y DevOps

1. El Buscador Mundial skills.sh y el Gestor npx skills (El "npm" de las Skills)

Como tanto Google Antigravity como Claude Code comparten el estándar abierto SKILL.md, la comunidad y Vercel Labs han creado un buscador centralizado llamado skills.sh y una herramienta de consola universal (npx skills) que funciona exactamente igual que npm pero para descargar e instalar Skills desde cualquier repositorio de GitHub directamente en tu carpeta .agents/skills/ o .claude/skills/.

Figura 1. Cómo buscar, descargar y conectar repositorios públicos de Skills (SKILL.md) en Google Antigravity. 

# 1. Buscar skills de DevOps, Docker, Kubernetes o React desde tu propia terminal:
npx skills find devops
npx skills find kubernetes
npx skills find react

# 2. Instalar automáticamente un repositorio o skill concreta en tu proyecto:
npx skills add anthropics/skills
npx skills add vercel-labs/agent-skills
npx skills add supabase/agent-skills
npx skills add ahmedasmar/devops-claude-skills
npx skills add antonbabenko/terraform-skill

# 3. Actualizar todas tus skills instaladas a su última versión:
npx skills update
Uso del gestor universal npx skills para buscar e instalar skills de cualquier repositorio de GitHub.

3. Cómo Conectar estos Repositorios en Antigravity con .agents/skills.json

Además de poder usar npx skills add, recuerda que en Antigravity puedes clonar esos repositorios en una carpeta central de tu ordenador y elegir qué skills activar en cada proyecto mediante .agents/skills.json:


# Clonas tus repositorios favoritos de Full Stack y DevOps:
mkdir -p ~/skills-catalog
git clone https://github.com/anthropics/skills.git ~/skills-catalog/anthropic
git clone https://github.com/vercel-labs/agent-skills.git ~/skills-catalog/vercel
git clone https://github.com/supabase/agent-skills.git ~/skills-catalog/supabase
git clone https://github.com/ahmedasmar/devops-claude-skills.git ~/skills-catalog/devops
git clone https://github.com/antonbabenko/terraform-skill.git ~/skills-catalog/terraform
git clone https://github.com/obra/superpowers.git ~/skills-catalog/superpowers
Clonado local de los principales repositorios de Full Stack y DevOps. 

{
