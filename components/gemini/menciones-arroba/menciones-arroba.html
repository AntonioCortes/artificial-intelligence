Menciones con @ (Añadir Archivos y Contexto Exacto)

1. ¿Para qué sirve escribir el símbolo @ en Gemini / Antigravity?

Imagina que tienes un proyecto con 300 archivos y le dices al agente: "Cambia el color del menú lateral". Aunque el agente es capaz de buscar por las carpetas hasta encontrar dónde está el archivo CSS del menú lateral, eso le llevará varios pasos y tiempo extra. En cambio, si escribes el símbolo @ en el cuadro de chat, se abrirá un menú desplegable interactivo de autocompletado que te permite adjuntar directamente el archivo o carpeta exacta a tu mensaje.

En cuanto escribes @ y empiezas a teclear parte del nombre (por ejemplo, @sidebar), Antigravity filtra al instante todos los elementos de tu proyecto para que solo tengas que pulsar Enter o Tab para seleccionarlo.

Figura 1. Las cinco categorías de contexto que puedes adjuntar instantáneamente usando el símbolo @ en Antigravity.

2. Todas las categorías que puedes mencionar con @

El menú de menciones @ de Antigravity no sirve únicamente para archivos sueltos; permite adjuntar cinco tipos distintos de contexto:

Categoría de Mención Cómo se escribe Qué hace exactamente
1. Archivos concretos @README.md o @js/main.js Inyecta o señala ese archivo exacto para que el agente lo lea de inmediato sin tener que buscarlo por el proyecto.
2. Carpetas completas @components/main-view/ Le indica al agente que centre su atención o tome como ejemplo todos los archivos contenidos dentro de ese directorio.
3. Sesiones de Terminal @terminal Pasa al agente el texto y los errores recientes que han salido en tu consola para que diagnostique un fallo sin copiar ni pegar.
4. Conversaciones previas @nombre-conversacion Conecta tu sesión actual con una conversación anterior para continuar un trabajo previo sin perder el contexto.
5. Reglas y Servidores MCP @GEMINI.md o @mcp Adjunta explícitamente una regla o una herramienta/recurso expuesto por un servidor MCP externo.

3. Ejemplos prácticos de Prompts combinando menciones con @

A continuación tienes ejemplos reales de cómo combinar varias menciones @ en una misma frase para que el agente entienda a la perfección qué archivos son la referencia y cuáles debe modificar:


# Ejemplo 1: Usar un archivo como guía y otro como destino
"Lee las instrucciones de @README.md y registra una nueva vista en
@components/common/assets/constants.json llamada 'claudeView'."

# Ejemplo 2: Usar una carpeta existente como plantilla para crear otra nueva
"Fíjate en cómo están estructurados los componentes dentro de @components/bootstrap/
y crea una estructura idéntica para nuestra nueva vista dentro de @components/gemini/."

# Ejemplo 3: Arreglar un fallo entre el HTML, el CSS y el JS
"El botón de colapsar el menú definido en @components/common/navbar.html no aplica
el color de @css/colors.css cuando se ejecuta la función de @js/sidebar.js. Revisa los tres."

4. Adjuntar Imágenes y Archivos Multimedia al Chat

Además del símbolo @, dado que Gemini es un modelo nativamente multimodal (es capaz de "ver" imágenes, diseños y capturas de pantalla igual que lee texto), en el lienzo de chat de Antigravity puedes:

  • Arrastrar y soltar (Drag & Drop) o Pegar (Ctrl + V): Puedes hacer una captura de pantalla de cómo se ve tu página web en el navegador o de un boceto de diseño y pegarla directamente en el chat diciendo: "Mira esta captura: la tabla se sale por la derecha en pantallas móviles, corrige el CSS en @css/content.css".
  • Incluir enlaces dentro de Archivos de Reglas: Incluso dentro de tus propios archivos de reglas (como GEMINI.md), puedes incluir referencias a otros documentos del proyecto usando la sintaxis Markdown y Antigravity las expandirá automáticamente al leer la regla.
