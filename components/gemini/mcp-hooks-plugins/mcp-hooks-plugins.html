Servidores MCP (Model Context Protocol) en Antigravity

1. ¿Qué es un MCP (Model Context Protocol)? Explicado sin tecnicismos

Si nunca has oído hablar de MCP (Model Context Protocol o Protocolo de Contexto de Modelos), la forma más fácil de entenderlo es con una analogía cotidiana: MCP es como el puerto USB-C universal para la Inteligencia Artificial.

Antes de que existiera el estándar MCP, la IA solo podía leer los archivos de tu carpeta local. Si querías que la IA consultara una tabla de tu base de datos PostgreSQL, leyera un ticket de Jira, revisara los Pull Requests pendientes en GitHub, inspeccionara un contenedor Docker o buscara un error en Sentry, no tenía forma directa de conectarse a esos programas. Con MCP, tú configuras pequeños conectores llamados Servidores MCP y, automáticamente, tu agente gana nuevas herramientas para hablar con bases de datos, APIs, navegadores y servicios externos de forma segura.

2. ¿Cómo se configura un Servidor MCP en Antigravity (mcp_config.json)?

En Antigravity, los servidores MCP se declaran en el archivo global ~/.gemini/config/mcp_config.json (o dentro de un plugin). Existen dos tipos de transporte para conectar un servidor MCP:

  • Transporte Stdio (Local): El agente ejecuta un programa instalado en tu propio ordenador (por ejemplo, con npx, Node.js, Python uvx o un binario Docker) y se comunica con él localmente por entrada/salida estándar.
  • Transporte Streamable HTTP (Remoto): El agente se conecta a una dirección web (url) de un servidor MCP remoto alojado en la nube o en la red interna de tu empresa.

{
  "mcpServers": {
    "postgres-local": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://usuario:pass@localhost:5432/midb"]
    },
    "playwright-browser": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    },
    "servidor-empresa-remoto": {
      "url": "https://mcp.miempresa.com/mcp"
    }
  }
}
Ejemplo de archivo ~/.gemini/config/mcp_config.json configurando servidores MCP locales (Postgres y Playwright) y uno remoto por HTTP.

3. Cómo Gestionar tus Servidores MCP desde el Chat y desde la Terminal

No necesitas editar el archivo JSON a mano cada vez que quieras activar, desactivar o añadir un servidor MCP. Antigravity te ofrece comandos tanto dentro del chat interactivo como en la terminal:


# 1. Dentro del chat interactivo (TUI), escribe:
/mcp                                        # Abre el panel interactivo de servidores MCP conectados

# 2. Desde tu terminal usando los subcomandos de agy mcp:
agy mcp list                                # Lista todos los servidores MCP configurados y su estado
agy mcp add mi-sqlite npx -y @modelcontextprotocol/server-sqlite ./datos.db
agy mcp enable mi-sqlite                    # Activa el servidor MCP
agy mcp disable mi-sqlite                   # Desactiva el servidor MCP cuando no lo necesites
agy mcp remove mi-sqlite                    # Elimina el servidor MCP de la configuración
Comandos para listar, añadir, activar y desactivar servidores MCP en Antigravity.

4. Los Servidores MCP Más Útiles para un Desarrollador Full Stack y DevOps

Servidor MCP Paquete / Conector Qué permite hacer a tu Agente
Playwright MCP @playwright/mcp Abrir un navegador real, probar tu web Full Stack, pulsar botones, leer errores de la consola JS y hacer capturas de pantalla.
PostgreSQL / SQLite MCP @modelcontextprotocol/server-postgres Consultar el esquema real de tus tablas, comprobar tipos de columnas y verificar consultas SQL directamente.
GitHub MCP github-mcp-server Leer Pull Requests, revisar logs de GitHub Actions fallidos, gestionar Issues y auditar alertas de seguridad.
Context7 MCP @upstash/context7-mcp Consultar en tiempo real la documentación oficial actualizada de cualquier librería o framework para evitar métodos obsoletos.
Docker / Kubernetes MCP mcp-server-docker / mcp-server-kubernetes Inspeccionar contenedores activos, leer logs de servicios caídos, consultar el estado de pods en K8s y diagnosticar redes.
