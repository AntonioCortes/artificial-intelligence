Reglas (GEMINI.md y AGENTS.md) y Memoria del Proyecto

1. ¿Qué es una Regla (Rule) explicada para principiantes?

Imagina que cada vez que contratas a un programador nuevo para ayudarte en esta página web tuvieras que explicarle desde cero: "Recuerda que los títulos llevan la clase title, que las tablas llevan table-striped, que los componentes se registran en components-imports.js...". Sería agotador repetirlo todos los días.

En Google Antigravity, las Reglas (Rules) son archivos de texto en formato Markdown (llamados GEMINI.md o AGENTS.md) que colocas dentro de tu proyecto. El agente los descubre y los lee automáticamente al empezar a trabajar sin que tú tengas que mencionarlos en el chat. Es, literalmente, la memoria permanente y el manual de normas de tu proyecto.

2. ¿Dónde se colocan las Reglas y cómo las descubre Antigravity?

Antigravity busca y aplica reglas siguiendo una jerarquía inteligente desde tu carpeta actual hacia arriba hasta la raíz del repositorio (donde está la carpeta .git), además de tu configuración global personal:

Nivel de Regla Ruta del Archivo Alcance y para qué sirve
1. Regla Global (Tu ordenador) ~/.gemini/config/GEMINI.md Se aplica a todos tus proyectos. Ideal para tus preferencias personales (ej: "Háblame siempre en español y explica los cambios paso a paso").
2. Regla Raíz del Proyecto ./GEMINI.md o ./AGENTS.md Se coloca en la carpeta principal del proyecto y se sube a Git para compartirla con todo tu equipo. Define la arquitectura y normas generales.
3. Reglas en Carpeta .agents .agents/rules/*.md Permite organizar múltiples archivos de reglas temáticos (por ejemplo: estilos-css.md, seguridad.md, testing.md).
4. Regla de Subcarpeta (Contextual) components/GEMINI.md Solo se activa cuando el agente abre o edita archivos dentro de esa subcarpeta concreta o sus carpetas hijas.

3. Ejemplo real de un archivo GEMINI.md para este mismo proyecto

Si quisieras crear un archivo GEMINI.md en la raíz de esta página web para que el agente conozca siempre las reglas del README.md sin tener que pedírselo nunca más, tendría este aspecto:


# Reglas del Proyecto: Plantilla Web Basada en WebComponents

## 1. Idioma y Estilo de Explicación
- Escribe todo el contenido de los componentes y comentarios en español.
- Las explicaciones deben ser didácticas, detalladas y con ejemplos claros.

## 2. Reglas Obligatorias de Maquetación HTML
- El título principal de cada componente debe usar: <h1 class="title">Título</h1>
- Todas las tablas deben llevar las clases: class="table table-striped table-hover"
- Todas las imágenes y diagramas deben llevar: class="center-horizontal"
- Debajo de cada tabla, imagen o bloque de código añade siempre un pie explicativo:
  <span class="center-horizontal caption">Texto explicativo</span>
- Los bloques de código deben ir en <div class="center-horizontal"><pre><code class="language-...">
  y tener siempre al menos 2 líneas para que el numerador de líneas funcione.

## 3. Registro de Nuevos Componentes y Vistas
- Cada componente debe tener su archivo .html y su .js con tagName empezando por "component-".
- Todo nuevo componente debe importarse en js/components-imports.js.
- Todo nuevo componente debe enlazarse en el sidebar.json de su vista.
Ejemplo completo de archivo GEMINI.md listo para usar en la raíz de un proyecto web.

4. Cómo gestiona Antigravity la memoria de las Reglas (Deduplicación y Límites)

Para que las reglas no llenen por completo la memoria (ventana de contexto) del modelo, Antigravity aplica tres mecanismos inteligentes:

  • Deduplicación automática: Aunque el agente pase varias veces por la misma carpeta, cada archivo de regla se inyecta una única vez por turno de conversación.
  • Activación bajo demanda (Progressive Disclosure): Las reglas de directorio solo se cargan cuando el agente trabaja con archivos de ese directorio, y las reglas con activación por decisión del modelo solo se leen completas cuando son relevantes para tu tarea.
  • Presupuesto de contexto protegido: Cada archivo de regla tiene un límite máximo de 24 KB y existe un presupuesto conjunto de 20.000 tokens para reglas activas, garantizando que siempre quede espacio de sobra para tus archivos y tu conversación.
