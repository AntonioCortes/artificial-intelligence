Dónde Conseguir Skills en Claude: Los Repositorios Más Famosos (Full Stack y DevOps)

1. Cómo Buscar y Descargar Cualquier Skill: skills.sh, npx skills y /plugin

Si te preguntas dónde se consiguen las Skills ya preparadas para no tener que escribirlas tú desde cero, hoy existen tres vías directas que conectan tu Claude Code con miles de carpetas SKILL.md creadas por Anthropic, Vercel, Supabase, Trail of Bits y la comunidad DevOps:

Figura 1. Repositorios de referencia de Skills, métodos de instalación en Claude Code y formas de invocación. 

# VÍA 1: Usar el gestor universal "npx skills" (del portal https://skills.sh) en tu terminal:
npx skills find devops                                   # Busca skills de DevOps en el registro mundial
npx skills find kubernetes                               # Busca skills de Kubernetes y Helm
npx skills add anthropics/skills                         # Instala las skills oficiales de Anthropic
npx skills add vercel-labs/agent-skills                  # Instala las skills oficiales de Vercel (React/Next/UI)
npx skills add supabase/agent-skills                     # Instala las skills oficiales de Supabase (PostgreSQL)
npx skills add ahmedasmar/devops-claude-skills           # Instala el pack completo de DevOps (Docker, K8s, CI/CD)
npx skills add antonbabenko/terraform-skill              # Instala la skill referente de Terraform / OpenTofu

# VÍA 2: Instalar repositorios de Skills directamente desde el chat de Claude con /plugin:
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills

# VÍA 3: Instalar el creador oficial de Skills de Anthropic para generar o mejorar las tuyas:
/plugin install skill-creator@claude-plugins-official
/skill-creator mi-skill-personalizada
Las tres formas de buscar e instalar repositorios de Skills en Claude Code en cuestión de segundos.

10. cloudflare/skills Oficial de Cloudflare (Edge, Workers y Redes) Skills oficiales para desarrollar y desplegar servicios en el Edge con Cloudflare Workers, bases de datos D1, almacenamiento R2, DNS y reglas de seguridad WAF.

11. alirezarezvani/claude-skills Catálogo de +150 Skills por Rol Técnico Incluye skills empaquetadas por especialidad como senior-fullstack, devops-engineer, aws-solution-architect, kubernetes-specialist y ci-cd-pipeline-builder.
