Servidores MCP en Claude Code (.mcp.json y claude mcp)

1. ¿Cómo funciona el protocolo MCP en Claude?

MCP (Model Context Protocol) fue creado originalmente como un estándar abierto por Anthropic y adoptado por toda la industria (incluyendo Google Antigravity). Gracias a ello, exactamente los mismos servidores MCP funcionan tanto en Claude como en Antigravity.

Al conectar un Servidor MCP en Claude Code, el agente adquiere acceso directo a bases de datos (PostgreSQL, Supabase, SQLite, Redis), navegadores reales (Playwright, Chrome DevTools), plataformas DevOps (GitHub, Cloudflare, Sentry, Grafana, Docker, Kubernetes) o gestores de tareas (Jira, Linear, Notion).

2. Cómo Añadir y Gestionar Servidores MCP desde la Terminal (claude mcp)

Claude Code incluye el subcomando claude mcp para que puedas añadir servidores remotos (HTTP/SSE) o locales (Stdio) eligiendo el ámbito (--scope local solo para ti en este proyecto, --scope project compartido con el equipo en .mcp.json, o --scope user global para todos tus proyectos):


# 1. Añadir un servidor MCP remoto por HTTP (ej. GitHub, Sentry o Context7)
claude mcp add --transport http github https://api.githubcopilot.com/mcp/

# 2. Añadir un servidor MCP local (Stdio) compartido con tu equipo (--scope project)
claude mcp add --scope project postgres -- npx -y @modelcontextprotocol/server-postgres postgresql://localhost/midb
claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest

# 3. Importar automáticamente los servidores MCP que ya tengas en Claude Desktop
claude mcp add-from-claude-desktop

# 4. Listar, inspeccionar o eliminar servidores MCP
claude mcp list
claude mcp get playwright
claude mcp remove postgres
Comandos oficiales de terminal para registrar, importar y administrar servidores MCP en Claude Code.

3. El Archivo .mcp.json para Compartir Servidores MCP con tu Equipo

Cuando ejecutas claude mcp add --scope project ... (o cuando creas el archivo manualmente), Claude guarda la configuración en el archivo .mcp.json en la raíz de tu repositorio Git. Incluso soporta expansión de variables de entorno (${VAR} o ${VAR:-valor_por_defecto}) para no subir contraseñas al repositorio:


{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    },
    "postgres-db": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "${DATABASE_URL:-postgresql://localhost:5432/dev}"]
    }
  }
}
Ejemplo de archivo .mcp.json compartido en Git utilizando variables de entorno seguras.

4. Gestión Interactiva con /mcp dentro del Chat

En cualquier momento durante una conversación puedes escribir /mcp para abrir el panel de estado en vivo: allí verás qué servidores MCP están conectados, cuántas herramientas aporta cada uno, podrás autenticarte con OAuth en servidores remotos (como GitHub, Linear o Sentry) o reconectar un servidor si se ha reiniciado tu base de datos local.
