Subagentes en Claude Code (.claude/agents/ y /agents)

1. ¿Qué son los Subagentes en Claude y cómo funcionan?

En Claude Code, los Subagentes son asistentes especializados que el agente principal puede lanzar (incluso varios en paralelo) para investigar el repositorio, planificar una arquitectura, revisar un Pull Request o ejecutar tests sin llenar ni ensuciar la ventana de contexto de tu conversación principal.

Cada subagente opera en su propia ventana de contexto aislada, tiene su propio prompt de sistema, una lista controlada de herramientas permitidas (tools) y puede usar un modelo distinto al de tu sesión principal (por ejemplo, usar el rapidísimo haiku para búsquedas masivas o opus para revisiones de arquitectura).

2. Subagentes Integrados de Serie en Claude Code

Subagente Nativo Modelo y Herramientas Cuándo lo lanza Claude automáticamente
Explore (Explorador rápido) Modelo rápido (Haiku) — Solo lectura (Glob, Grep, Read). Cuando necesita buscar en decenas de archivos del repositorio para entender cómo está construido un módulo sin gastar tokens de tu sesión principal.
Plan (Arquitecto) Solo lectura e investigación arquitectónica. Durante el Plan Mode para explorar el impacto de un cambio grande y diseñar los pasos de implementación.
general-purpose Acceso completo a las herramientas autorizadas. Cuando le pides tareas complejas de varios pasos o le dices "lanza subagentes en paralelo para revisar cada carpeta" (fan out subagents).

3. Cómo Crear tus Propios Subagentes (/agents o .claude/agents/*.md)

Puedes crear tus propios subagentes mediante el asistente interactivo escribiendo /agents en el chat, o bien creando un archivo Markdown en .claude/agents/ (para compartirlo con tu equipo en Git) o en ~/.claude/agents/ (para todos tus proyectos):


---
name: validador-web
description: >-
  Experto en verificar que los componentes WebComponent, el archivo sidebar.json
  y js/components-imports.js cumplen todas las reglas del README.md. Úsalo de forma
  proactiva después de crear o editar componentes.
tools: Read, Grep, Glob, Bash
model: sonnet
effort: high
---

Eres un auditor de calidad para esta plantilla web SPA. Cuando te invoquen:
1. Comprueba que cada componente creado tiene su archivo .html y su .js.
2. Verifica que todos los archivos .js están importados en js/components-imports.js.
3. Revisa que todas las tablas tienen las clases "table table-striped table-hover"
   y que los bloques de código tienen al menos 2 líneas.
Devuelve un informe claro indicando si todo es válido o qué archivo falta corregir.
Ejemplo real de un Subagente personalizado guardado en .claude/agents/validador-web.md.

4. Opciones Avanzadas en la Cabecera YAML de un Subagente

Campo YAML Valores admitidos Para qué sirve
name y description Texto obligatorio Identificador del subagente y explicación de cuándo debe invocarlo Claude de forma automática.
tools / disallowedTools Read, Grep, Glob, Bash, Edit, Write... Restringe qué herramientas puede usar el subagente (por ejemplo, limitarlo solo a lectura para que sea 100% seguro).
model y effort sonnet, opus, haiku, inherit Elige qué modelo de Claude y qué nivel de esfuerzo de razonamiento utiliza ese subagente.
isolation: worktree worktree (opcional) Ejecuta el subagente dentro de un Git Worktree temporal aislado para que pueda editar y probar código en paralelo sin colisionar con otros subagentes.
background: true true / false Hace que el subagente se ejecute siempre como tarea en segundo plano sin bloquear tu chat.
