Marketplaces y Catálogo de Plugins en Claude (Full Stack y DevOps)

1. ¿Dónde ver el listado de todos los Plugins disponibles en Claude Code?

Para ver todos los plugins que existen e instalarlos con un clic, Claude Code cuenta con un sistema de Tiendas o Catálogos de Plugins (Marketplaces):

  1. Desde dentro de Claude Code (Buscador Visual): Escribe /plugin (o /plugins) en el chat. Se abrirá una interfaz interactiva con pestañas por las que puedes moverte con Tab y las flechas:
    • Discover: Te muestra todo el listado de plugins disponibles para instalar desde tus Marketplaces activos, con buscador por texto.
    • Installed: Muestra los plugins que ya tienes instalados para activarlos, desactivarlos o actualizarlos.
    • Marketplaces: Muestra qué catálogos tienes conectados y te permite añadir nuevos repositorios.
  2. En la Web (GitHub Oficial de Anthropic): Puedes explorar todas las carpetas y leer el código fuente de cada plugin oficial en github.com/anthropics/claude-plugins-official y en github.com/anthropics/claude-code/tree/main/plugins.

3. Catálogo Extenso de Plugins para Desarrollador Full Stack y DevOps

Aquí tienes la selección completa de los plugins más útiles para tu perfil Full Stack + DevOps, divididos en 3 tablas con el comando exacto de instalación listo para copiar y pegar:

3.1. Plugins Oficiales de Flujo de Trabajo, Git, Pull Requests y Seguridad

Plugin Comando Exacto de Instalación Qué añade y por qué te interesa
commit-commands /plugin install commit-commands@claude-plugins-official Añade /commit, /commit-push-pr y /clean_gone. Analiza tus cambios, redacta el commit, sube la rama, abre el Pull Request y limpia ramas locales ya fusionadas.
feature-dev /plugin install feature-dev@claude-plugins-official Añade /feature-dev y 3 subagentes (code-explorer, code-architect, code-reviewer). Guía el desarrollo de funcionalidades Full Stack en 7 fases estructuradas.
pr-review-toolkit /plugin install pr-review-toolkit@claude-plugins-official Añade /pr-review-toolkit:review-pr con 6 subagentes que revisan fallos silenciosos, cobertura de tests, diseño de tipos, comentarios y simplicidad del código.
code-review /plugin install code-review@claude-plugins-official Añade /code-review: audita tus cambios con 4 subagentes en paralelo y puntúa la certeza de cada bug de 0 a 100 para mostrar solo problemas reales.
security-guidance /plugin install security-guidance@claude-plugins-official Hook preventivo DevSecOps que vigila cada edición y avisa si se intenta introducir inyección de comandos, XSS, uso de eval() o fallos de seguridad en GitHub Actions.
hookify /plugin install hookify@claude-plugins-official Añade /hookify: crea hooks y guardarraíles de seguridad a medida escribiendo en lenguaje natural (sin tener que programar JSON).
skill-creator /plugin install skill-creator@claude-plugins-official Añade /skill-creator: entrevista interactiva y sistema de evaluación (evals) oficial de Anthropic para crear y optimizar tus propias Skills.
