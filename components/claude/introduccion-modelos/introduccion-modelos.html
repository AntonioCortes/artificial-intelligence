¿Qué es Claude y qué Modelos existen?

1. ¿Qué es Claude? Introducción desde cero

Claude es la familia de modelos de Inteligencia Artificial y herramientas agénticas desarrollada por Anthropic. Entre los desarrolladores de software, redactores y analistas técnicos, Claude se ha hecho enormemente popular por tres cualidades principales:

  • Altísima precisión escribiendo y refactorizando código: Entiende proyectos grandes, respeta las convenciones de estilo existentes y genera código muy limpio.
  • Comunicación natural y estructurada: Sus explicaciones son claras, directas y menos propensas a repetir frases robóticas.
  • Ecosistema Agéntico Completo (Claude Code): Al igual que Google cuenta con Antigravity para Gemini, Anthropic ofrece Claude Code, su herramienta agéntica oficial que trabaja directamente sobre los archivos de tu ordenador desde la terminal o integrada en tu editor (VS Code / JetBrains).

2. Los 3 Modelos de Claude: Haiku, Sonnet y Opus

Los nombres de los modelos de Claude están inspirados en tipos de composiciones poéticas, ordenados de menor a mayor tamaño y profundidad. Saber cuándo elegir cada uno (por ejemplo, usando el comando /model) es fundamental:

Modelo Características Clave Cuándo debes elegirlo
Claude Haiku Es el modelo más pequeño, ultrarrápido y muy económico en consumo de tokens. Para preguntas rápidas, transformar formatos sencillos (JSON/CSV), explicar un comando corto o para que lo usen subagentes que solo buscan archivos.
Claude Sonnet El equilibrio perfecto entre inteligencia avanzada y rapidez de respuesta. Es el modelo por defecto recomendado para el 90% del trabajo diario: crear componentes, programar funciones, escribir tests y usar el agente.
Claude Opus El modelo más grande y con mayor capacidad de razonamiento profundo de Anthropic. Para decisiones de arquitectura críticas, encontrar errores muy sutiles en múltiples archivos o planificar refactorizaciones complejas.

3. ¿Qué es el Pensamiento Extendido (Extended Thinking)?

Tanto en Claude Sonnet como en Claude Opus existe una capacidad llamada Extended Thinking (Pensamiento Extendido). Cuando está activada, antes de escribir una sola línea de respuesta o de código, Claude abre un bloque interno de reflexión donde desglosa el problema, comprueba casos límite y diseña la solución.

En Claude Code, incluso puedes controlar cuánto quieres que piense en una tarea difícil mediante palabras clave en tu propio prompt (como "think", "think hard" o "ultrathink") o activando el pensamiento extendido en el selector de modelo con /model.

4. Diferencia entre Claude Web/Desktop y Claude Code

Puedes usar Claude de dos maneras muy distintas según tu objetivo:

  1. Claude Web y Desktop App (claude.ai): Es la interfaz de chat visual. Incluye dos funciones muy útiles para principiantes:
    • Artifacts (Artefactos): Cuando le pides a Claude que cree un diagrama, una calculadora en HTML/React o un documento, se abre un panel a la derecha donde puedes ver y probar el resultado en vivo sin salir del chat.
    • Projects (Proyectos): Te permite crear un espacio donde subes documentos PDF, manuales o archivos de referencia e instrucciones personalizadas para que todas las conversaciones de ese proyecto los tengan presentes.
  2. Claude Code (El Agente en tu Terminal e IDE): En lugar de subir archivos a una web, abres tu terminal en la carpeta de tu proyecto y ejecutas el comando claude. El agente vive directamente dentro de tu proyecto: lee tus carpetas, edita tus archivos, ejecuta tus tests y se conecta a tus servidores MCP.

# 1. Instalar Claude Code globalmente (requiere tener Node.js instalado)
npm install -g @anthropic-ai/claude-code

# 2. Entrar en la carpeta de tu proyecto web y lanzar el agente
cd /ruta/a/mi-proyecto-web
claude
