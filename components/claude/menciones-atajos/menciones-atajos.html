Menciones con @, Modo Bash !, Memoria # y Atajos en Claude

1. Los cuatro símbolos mágicos al escribir en Claude Code

En Claude Code, el primer carácter o símbolo que escribes en el cuadro de entrada puede activar funciones especiales que te ahorran muchísimo tiempo. Dominar estos cuatro símbolos (@, !, # y /) marca la diferencia entre un usuario principiante y un usuario avanzado:

Figura 1. Los cuatro prefijos interactivos (@, !, # y /) y los atajos de teclado esenciales en Claude Code.

2. Cómo mencionar archivos y carpetas concretas con @

Igual que en Antigravity, en Claude no necesitas copiar y pegar el contenido de un archivo dentro del chat ni explicar toda la ruta letra por letra. Cuando estás escribiendo tu prompt y pulsas la tecla @:

  1. Se abre instantáneamente un buscador con todos los archivos y carpetas de tu proyecto.
  2. Empiezas a escribir cualquier parte del nombre del archivo (por ejemplo, @const para encontrar components/common/assets/constants.json) y pulsas Tab o Enter para autocompletarlo.
  3. Al enviar el mensaje, Claude incluye automáticamente ese archivo completo en su contexto antes de responderte.
  • Mencionar un archivo suelto: Explica qué hace la función changeContent en @js/sidebar.js
  • Mencionar una carpeta entera: Revisa todos los componentes dentro de @components/main-view/ y dime cuántos hay
  • Mencionar recursos de servidores MCP: Si tienes servidores MCP conectados, también aparecerán en la lista desplegable al pulsar @ para que puedas adjuntar issues de GitHub, documentos o esquemas de bases de datos.

3. El Modo Bash directo (!) y la Memoria rápida (#)

Además de @, Claude Code incorpora dos prefijos rapidísimos cuando los escribes al comienzo de una línea vacía:

  • Prefijo ! (Modo Bash Instantáneo): Si escribes un signo de exclamación ! al principio de la línea (por ejemplo, ! git status o ! npm test), el comando se ejecuta directamente en tu terminal en milisegundos (sin esperar a que el modelo de IA piense) y tanto el comando como su resultado quedan guardados dentro de la conversación actual para que Claude los vea en tu siguiente pregunta.
  • Prefijo # (Añadir a la Memoria CLAUDE.md): Si empiezas tu mensaje con una almohadilla # (por ejemplo, # Recuerda siempre importar los nuevos componentes en js/components-imports.js), Claude te preguntará en qué archivo de memoria CLAUDE.md quieres guardar esa regla para recordarla en todas las futuras sesiones.

4. Atajos de teclado imprescindibles en Claude Code

Atajo de Teclado Qué hace Por qué es tan útil
Shift + Tab Alterna entre Modo Normal, Auto-Accept Edits y Plan Mode. Te permite pasar de planificar sin riesgo a ejecutar a toda velocidad con una sola pulsación.
Esc (Una vez) Detiene en seco lo que Claude está haciendo en ese instante (sin borrar la conversación). Si ves que Claude está editando el archivo equivocado o yendo por otro camino, lo paras al instante y lo rediriges.
Esc + Esc (Dos veces) Abre el historial de mensajes para rebobinar (Rewind) la conversación y el código a un punto anterior. Si una idea no ha salido bien, puedes "viajar atrás en el tiempo" varios pasos en el chat como si nunca hubieran ocurrido.
Ctrl + V (o arrastrar imagen) Pega una imagen o captura de pantalla del portapapeles directamente en el chat. Ideal para enseñarle a Claude cómo se ve un error visual en el navegador o pasarle un diagrama de diseño.
\ + Enter (o Option + Enter) Inserta un salto de línea sin enviar todavía el mensaje. Permite escribir prompts largos de varios párrafos o listas ordenadas cómodamente en la terminal.
