Gran Comparativa: Equivalencias entre Gemini (Antigravity) y Claude

1. Diccionario Traductor Definitivo: Google Antigravity vs Claude Code

Si trabajas tanto con Gemini / Google Antigravity (AGY) como con Claude / Claude Code, verás que ambas plataformas comparten la misma filosofía de desarrollo agéntico e incluso son compatibles entre sí en estándares clave como Skills (SKILL.md), Plugins y Servidores MCP.

Esta gran tabla comparativa te servirá de referencia rápida para saber cómo se llama, qué comando usa y en qué archivo se guarda cada concepto en una y otra herramienta:

Concepto / Funcionalidad En Gemini / Google Antigravity (AGY) En Claude / Claude Code
Modelos (Rápido / Diario / Profundo) Gemini Flash Lite (flash_lite) / Gemini Flash (flash) / Gemini Pro (pro) Claude Haiku (haiku) / Claude Sonnet (sonnet) / Claude Opus (opus)
Niveles de Esfuerzo (Thinking) /model o agy --effort (low, medium, high, xhigh, max) /effort o claude --effort (low, medium, high, xhigh, max)
Comando para abrir en Terminal agy (Modo headless: agy -p "prompt") claude (Modo headless: claude -p "prompt")
Reanudar última conversación agy -c (o comando interno /resume) claude -c / claude -r (o comando interno /resume)
Archivo de Reglas / Memoria del Proyecto GEMINI.md o AGENTS.md (y .agents/rules/*.md) CLAUDE.md (y .claude/rules/*.md)
Memoria Global de Usuario ~/.gemini/config/GEMINI.md ~/.claude/CLAUDE.md
Mencionar archivos y contexto Símbolo @ (@archivo, @carpeta, @terminal, @mcp) Símbolo @ (@archivo, @carpeta, @mcp) + ! (Bash directo) + # (Memoria)
Planificar antes de programar Comandos /plan, /grill-me, agy --mode plan o Artefactos de Plan Pulsar Shift + Tab (Plan Mode), comando /plan o --permission-mode plan
Comprimir o limpiar conversación /compact (resumir) y /clear / /new (limpiar) /compact (resumir) y /clear (limpiar)
Carpeta de Skills (Habilidades) .agents/skills/<nombre>/SKILL.md (y .agents/skills.json) .claude/skills/<nombre>/SKILL.md y comandos en .claude/commands/*.md
Ver listado de Skills activas Comando /skills Comando /skills
Subagentes en paralelo research, self, image-generator, /subagents y /teamwork Explore, Plan, archivos .claude/agents/*.md y comando /agents
Configuración de Servidores MCP ~/.gemini/config/mcp_config.json, /mcp y agy mcp ... .mcp.json en el proyecto, /mcp y claude mcp ...
Hooks del Ciclo de Vida .agents/hooks.json (y ~/.gemini/config/hooks.json) .claude/settings.json (sección hooks) y comando /hooks
Plugins y Extensiones .agents/plugins/<nombre>/plugin.json, /plugins y agy plugin install (acepta los 3 formatos) .claude-plugin/plugin.json, /plugin, claude plugin y claude marketplace
SDK Oficial para Programar Agentes Antigravity Python SDK (pip install google-antigravity) Claude Agent SDK (TypeScript y Python — plugin agent-sdk-dev)
