2. Cómo crear y usar Subagentes en Claude (.claude/agents/)

En Claude Code puedes crear Subagentes especializados ejecutando el comando interactivo /agents o creando directamente un archivo Markdown dentro de la carpeta .claude/agents/ de tu proyecto (o en ~/.claude/agents/ para tenerlos en todos tus proyectos).

Cada subagente tiene su propia ventana de contexto independiente, su propio prompt de sistema, una lista opcional de herramientas permitidas (tools) y hasta puedes elegir qué modelo usa (model: sonnet, opus o haiku). Claude delegará tareas automáticamente en tu subagente cuando vea que encaja con su descripción, o tú mismo puedes pedírselo diciendo: "Usa el subagente validador-web para revisar los componentes nuevos".


---
name: validador-web
description: >-
  Experto en verificar que los componentes WebComponent, el archivo sidebar.json
  y js/components-imports.js cumplen todas las reglas del README.md. Úsalo de forma
  proactiva después de crear o editar componentes.
tools: Read, Grep, Glob, Bash
model: sonnet
---

Eres un auditor de calidad para esta plantilla web SPA. Cuando te invoquen:
1. Comprueba que cada componente creado tiene su archivo .html y su .js.
2. Verifica que todos los archivos .js están importados en js/components-imports.js.
3. Revisa que todas las tablas tienen las clases "table table-striped table-hover"
   y que los bloques de código tienen al menos 2 líneas.
Devuelve un informe claro indicando si todo es válido o qué archivo falta corregir.
Ejemplo real de un Subagente guardado en .claude/agents/validador-web.md.

3. Cómo conectar Servidores MCP en Claude (.mcp.json)

Recuerda que MCP (Model Context Protocol) fue creado originalmente como un estándar abierto por Anthropic y adoptado por toda la industria (incluyendo Google Antigravity). Por tanto, los mismos servidores MCP sirven para ambos.

En Claude Code puedes añadir servidores MCP directamente desde tu terminal con el comando claude mcp add, o compartirlos con todo tu equipo guardándolos en el archivo .mcp.json en la raíz del proyecto:


# Opción A: Añadir un servidor MCP desde la terminal con el comando claude mcp add
claude mcp add --transport http github https://api.githubcopilot.com/mcp/

# Opción B: Añadir un servidor MCP local (Stdio) compartido con el equipo (--scope project)
claude mcp add --scope project sqlite -- npx -y @modelcontextprotocol/server-sqlite ./datos.db

# Ver todos los servidores MCP configurados
claude mcp list
Comandos de consola para añadir y listar servidores MCP en Claude Code.

Cuando usas --scope project, Claude crea en la raíz de tu proyecto un archivo .mcp.json como este:


{
  "mcpServers": {
    "sqlite": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sqlite", "./datos.db"]
    }
  }
}
Archivo .mcp.json en la raíz del proyecto para compartir servidores MCP con tu equipo.

4. Hooks y Configuración en Claude (.claude/settings.json)

Al igual que hooks.json en Antigravity, en Claude puedes configurar Hooks y permisos dentro del archivo .claude/settings.json para que se ejecuten comandos automáticos en eventos como PreToolUse, PostToolUse, Notification o Stop.
