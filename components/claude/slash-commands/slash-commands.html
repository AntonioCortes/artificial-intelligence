Todos los Comandos con / (Slash Commands) en Claude

1. ¿Qué aparece cuando pulsas / en Claude?

Al escribir una barra / en Claude Code (tanto en la terminal como en la extensión de tu editor), se despliega una lista con todos los comandos integrados de control, memoria, agentes, modelos y diagnóstico, además de los comandos personalizados que hayas creado tú o tu equipo.

Para alguien que está aprendiendo desde cero, conocer estos comandos es fundamental porque te permiten inicializar un proyecto nuevo en segundos, limpiar o resumir la memoria para no gastar tokens de más, cambiar de modelo o crear subagentes mediante menús guiados.

2. Guía completa de los Comandos / esenciales en Claude

Comando Función Principal Explicación detallada y cuándo usarlo
/init Inicializar el proyecto (CLAUDE.md) El primer comando que debes ejecutar en cualquier proyecto nuevo. Claude analiza tus carpetas, tu README y tus scripts y genera automáticamente un archivo CLAUDE.md con toda la guía del proyecto.
/clear Vaciar la conversación actual Borra por completo el historial del chat actual para empezar una tarea nueva desde cero con la ventana de contexto 100% limpia. Úsalo siempre que cambies de tarea.
/compact [foco] Comprimir y resumir el contexto Cuando la conversación es muy larga pero quieres seguir en la misma tarea, resume todo lo hablado hasta ahora ahorrando hasta un 80% de tokens. Puedes indicarle en qué centrarse (ej. /compact conserva las reglas de estilos CSS).
/model Cambiar de modelo de IA Abre un selector para elegir entre Claude Sonnet (uso diario), Claude Opus (máximo razonamiento) o Claude Haiku (máxima rapidez), y configurar el pensamiento extendido.
/memory Editar la memoria del proyecto Permite abrir y editar directamente desde tu editor tu archivo CLAUDE.md del proyecto o tu memoria global de usuario (~/.claude/CLAUDE.md).
/agents Gestionar Subagentes Abre un menú interactivo para ver, crear, editar o eliminar Subagentes especializados (tanto a nivel de proyecto como personales) sin tener que escribir el archivo a mano.
/mcp Estado de Servidores MCP Muestra qué servidores MCP están conectados, qué herramientas exponen, si alguno ha dado error de conexión y permite iniciar sesión (OAuth) en servidores remotos.
/permissions Configurar permisos de herramientas Permite ver y modificar la lista blanca de comandos de terminal, lecturas o ediciones que Claude tiene permiso para ejecutar sin preguntarte cada vez.
/review Revisión de código / Pull Request Pide a Claude que analice los últimos cambios realizados en el código o en un Pull Request buscando posibles errores, fallos de seguridad o mejoras.
/resume Retomar una conversación pasada Abre una lista con tus sesiones anteriores en ese proyecto para que puedas continuar exactamente donde lo dejaste ayer.
/cost y /status Ver consumo de tokens y estado Muestra cuántos tokens llevas consumidos en la sesión actual, qué modelo está activo y el estado de tu cuenta y configuración.
/doctor y /help Diagnóstico y ayuda /doctor comprueba si tu instalación de Claude Code tiene algún problema, y /help lista todos los comandos nativos y personalizados.

3. Ejemplo práctico: Cómo usar los comandos / durante un día de trabajo


# 1. Entras por primera vez a este proyecto web y generas su memoria automática:
/init

# 2. Le pides a Claude que cree toda la vista de Gemini:
> Crea la vista de Gemini en components/gemini con sus 9 componentes y diagramas SVG.

# 3. La conversación ya tiene muchos mensajes, pero ahora quieres crear la vista de Claude
#    conservando en memoria cómo funciona el proyecto:
/compact conserva el resumen de las reglas del README y los archivos ya creados

# 4. Quieres cambiar temporalmente a Claude Opus para diseñar una arquitectura compleja:
/model

# 5. Has terminado por completo y vas a empezar otro tema que no tiene nada que ver:
/clear
Flujo de uso real combinando /init, /compact, /model y /clear para mantener la máxima eficacia.
