Skills y Comandos Personalizados en Claude: Qué son y Cómo Crearlos

1. ¿Cuál es la diferencia entre una Skill (.claude/skills/) y un Comando (.claude/commands/)?

En Claude Code dispones de dos mecanismos complementarios para enseñar a Claude procedimientos a medida sin saturar el archivo CLAUDE.md:

Característica Comandos Personalizados (.claude/commands/) Skills / Habilidades (.claude/skills/)
Formato Un único archivo Markdown suelto (.claude/commands/mi-comando.md). Una carpeta completa (.claude/skills/mi-skill/SKILL.md) que puede incluir scripts (scripts/), plantillas y referencias (references/).
Cómo se activa Lo disparas tú manualmente escribiendo /mi-comando en el chat. Doble vía: Claude puede activarla automáticamente por sí solo cuando detecta que tu tarea coincide con su description, y también puedes invocarla manualmente con /mi-skill.
Cuándo elegirlo Para prompts repetitivos rápidos que quieres lanzar bajo demanda (ej. /nuevo-componente). Para flujos técnicos completos (Full Stack, DevOps, Testing) que incluyen checklists, scripts de validación o documentación auxiliar.

2. Cómo crear un Comando Personalizado con / y $ARGUMENTS

Cualquier archivo Markdown (.md) que guardes dentro de .claude/commands/ (en tu proyecto) o en ~/.claude/commands/ (para todos tus proyectos) aparece inmediatamente en el menú desplegable /. Si usas la variable especial $ARGUMENTS, Claude la reemplazará por el texto que escribas detrás del comando:


# Archivo: .claude/commands/nuevo-componente.md
---
description: Crea un nuevo componente WebComponent y lo registra en el sidebar e imports
---

Sigue las reglas de @README.md para crear un nuevo componente con estos datos: $ARGUMENTS

1. Crea la carpeta, el archivo .html y el archivo .js usando createComponent().
2. Asegúrate de que el título principal lleve class="title" y las tablas lleven
   class="table table-striped table-hover".
3. Registra el import en @js/components-imports.js y enlázalo en el sidebar.json correspondiente.
Ejemplo de comando personalizado guardado en .claude/commands/nuevo-componente.md. 

# Cómo invocarías tu nuevo comando personalizado desde el chat de Claude:
/nuevo-componente dentro de la vista claude llamado "subagentes" sobre agentes en paralelo
Invocación del comando personalizado pasando argumentos dinámicos a $ARGUMENTS.

3. Cómo crear tu propia Skill en .claude/skills/<nombre>/SKILL.md

Para crear una Skill en Claude Code (que además será 100% compatible con Google Antigravity), creas una carpeta dentro de .claude/skills/ con un archivo SKILL.md que empiece con un bloque YAML (---):


---
name: auditar-docker-devops
description: >-
  Revisa y optimiza archivos Dockerfile y docker-compose.yml aplicando buenas
  prácticas de seguridad, multi-stage builds y caché. Úsala automáticamente
  cuando el usuario pida crear, revisar o depurar contenedores Docker.
---

# Guía de Auditoría Docker y DevOps

Cuando revises o crees un `Dockerfile` o `docker-compose.yml`:
1. Utiliza siempre compilación multi-etapa (*multi-stage build*) para reducir el tamaño final.
2. Asegúrate de que el contenedor se ejecute con un usuario sin privilegios (`USER node` o `USER appuser`).
3. Define un bloque `HEALTHCHECK` real y fija versiones exactas en las imágenes base (`FROM node:22-alpine`).
4. Ejecuta el script `./scripts/validar-imagen.sh` para comprobar que construye sin errores.
Ejemplo real de archivo .claude/skills/auditar-docker-devops/SKILL.md.

Recuerda que puedes consultar todas las Skills que Claude ha detectado en tu sesión escribiendo el comando /skills en el chat.
