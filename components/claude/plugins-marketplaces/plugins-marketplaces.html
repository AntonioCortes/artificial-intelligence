Plugins en Claude Code: Qué son, Cómo Funcionan y Cómo Crearlos

1. ¿Qué es exactamente un Plugin en Claude Code y qué hace?

En Claude Code, un Plugin es un paquete todo-en-uno (identificado por un archivo manifiesto .claude-plugin/plugin.json) que amplía de golpe las capacidades de Claude sin que tengas que copiar ni configurar archivos sueltos uno por uno.

Mientras que una Skill es únicamente un manual de instrucciones para una tarea concreta, un solo Plugin de Claude puede inyectar hasta 7 componentes distintos automáticamente en cuanto lo instalas:

  1. Skills (skills/) y Comandos con barra (commands/): Añade nuevas órdenes al menú / (por ejemplo /commit, /review-pr o /feature-dev) y habilidades que Claude activa por sí solo cuando las necesita.
  2. Subagentes especializados (agents/): Incorpora un equipo de subagentes preconfigurados (como revisores de seguridad, arquitectos de código o analistas de tests).
  3. Servidores MCP (.mcp.json): Arranca y conecta automáticamente servidores MCP (como Playwright para controlar el navegador, PostgreSQL, Supabase, GitHub, Sentry o Figma) sin que tengas que configurarlos a mano.
  4. Hooks del ciclo de vida (hooks/hooks.json): Activa scripts automáticos antes o después de que Claude edite archivos o ejecute comandos en Bash (por ejemplo, para impedir prácticas inseguras o formatear código).
  5. Servidores de Lenguaje LSP (.lsp.json): Conecta motores de análisis de código (TypeScript, Python Pyright, Go, Rust) para que Claude navegue a definiciones y detecte errores de tipos al instante.
  6. Estilos de salida, temas y flujos (output-styles/, themes/, workflows/): Personaliza el formato de respuesta y el comportamiento visual.

2. Cómo Gestionar tus Plugins desde el Chat (/plugin) y desde la Terminal (claude plugin)

Claude Code trae integrado un gestor completo de plugins tanto dentro de la sesión interactiva como desde la consola de comandos:


# 1. DENTRO DEL CHAT INTERACTIVO DE CLAUDE CODE:
/plugin                                             # Abre el menú interactivo con pestañas (Discover, Installed, Marketplaces)
/plugin install frontend-design@claude-plugins-official
/plugin install playwright@claude-plugins-official
/reload-plugins                                     # Recarga en caliente los plugins recién instalados o editados

# 2. DESDE LA TERMINAL DE COMANDOS (FUERA DEL CHAT):
claude plugin list                                  # Muestra todos los plugins instalados y cuáles están activos
claude plugin install commit-commands@claude-plugins-official
claude plugin install supabase@claude-plugins-official --scope project
claude plugin enable nombre-plugin                  # Activa un plugin instalado
claude plugin disable nombre-plugin                 # Desactiva un plugin para ahorrar contexto cuando no lo uses
claude plugin update nombre-plugin                  # Actualiza el plugin a su última versión
claude plugin validate ./mi-plugin                  # Verifica que tu plugin cumpla el esquema oficial
claude plugin uninstall nombre-plugin               # Desinstala el plugin
Todos los comandos interactivos y de consola para instalar, activar, desactivar, actualizar y validar plugins en Claude Code.

3. Estructura de Carpetas: Cómo Crear tu Propio Plugin en Claude (.claude-plugin/plugin.json)

Si quieres empaquetar las Skills, Subagentes, Hooks y Servidores MCP de tu equipo Full Stack o DevOps para que cualquier compañero los instale con un solo comando (o cargarlo en local con claude --plugin-dir ./mi-plugin), solo necesitas esta estructura de directorios:


mi-plugin-equipo/
├── .claude-plugin/
│   └── plugin.json          # Manifiesto obligatorio con nombre, versión y descripción
├── .mcp.json                # Opcional: Servidores MCP que arranca el plugin
├── .lsp.json                # Opcional: Servidores de lenguaje (TypeScript, Python, Go...)
├── hooks/
│   └── hooks.json           # Opcional: Hooks PreToolUse / PostToolUse / Stop
├── agents/
│   └── revisor-devops.md    # Opcional: Subagentes incluidos en el plugin
├── commands/
│   └── desplegar.md         # Opcional: Comandos / personalizados del plugin
└── skills/
    └── auditoria-api/
        └── SKILL.md         # Opcional: Skills bajo demanda incluidas en el plugin
Estructura oficial de un paquete de Plugin en Claude Code. 

{

  "author": {
    "name": "Equipo de Ingeniería"
  }
}

4. Consejo de Rendimiento: Activar Plugins por Proyecto (--scope project)

El propio Claude Code incluye un aviso inteligente (plugin-disuse-review): tener 20 plugins activados a la vez cuando no los estás usando consume parte de tu ventana de contexto inicial. La mejor práctica es dejar activos globalmente (--scope user) tus 3 o 4 plugins de cabecera (como commit-commands y security-guidance) y activar por proyecto (--scope project, que se guarda en .claude/settings.json) los específicos de ese repositorio (como frontend-design, playwright o supabase).
