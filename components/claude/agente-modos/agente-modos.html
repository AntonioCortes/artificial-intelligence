El Agente de Claude y sus Modos de Ejecución

1. ¿Cómo trabaja el Agente en Claude Code?

Cuando abres Claude Code en tu proyecto (ya sea desde la terminal escribiendo claude o usando la extensión oficial en VS Code / Cursor / JetBrains), no estás ante un simple chat de texto: estás frente a un agente autónomo con herramientas integradas.

Por sí mismo, y sin que tengas que instalar nada adicional, el agente de Claude dispone de herramientas nativas para:

  • Explorar y buscar en tu proyecto (Read / Glob / Grep): Busca archivos por nombre y encuentra en milisegundos en qué línea exacta de qué archivo aparece una función o una clase CSS.
  • Crear y editar archivos (Edit / Write): Modifica líneas específicas de tus archivos existentes o crea carpetas y archivos nuevos desde cero.
  • Ejecutar comandos de consola (Bash): Puede lanzar el servidor de pruebas, ejecutar git status, instalar paquetes con npm o validar que un archivo JSON sea válido.
  • Buscar en la web y consultar documentación (WebFetch / WebSearch): Si necesita consultar la documentación actualizada de una librería, puede leerla directamente.
  • Lanzar Subagentes (Task / Agent): Puede abrir agentes secundarios en paralelo para investigar el código o dividir una tarea grande.

2. Los 3 Modos de Ejecución en Claude Code (Shift + Tab)

Uno de los secretos mejor guardados para usar Claude como un profesional es saber cambiar entre sus tres modos de ejecución pulsando la combinación de teclas Shift + Tab en cualquier momento:

Figura 1. Los tres modos de ejecución de Claude Code y el flujo recomendado pasando de Plan Mode a Auto-Accept Edits.
  1. Plan Mode (Modo Planificación - Solo Lectura): Al pulsar Shift + Tab hasta ver el indicador Plan Mode on, Claude entra en un estado 100% seguro donde solo puede leer e investigar tu proyecto, pero tiene prohibido modificar archivos. Analiza tu código, te explica qué archivos hay que tocar y te presenta un plan detallado paso a paso.
  2. Normal Mode (Modo por defecto con confirmación): Cada vez que Claude quiere editar un archivo o ejecutar un comando en la terminal, se detiene, te muestra en pantalla el cambio exacto (en verde lo que añade y en rojo lo que quita) y te pregunta si lo apruebas para esta vez o para toda la sesión.
  3. Auto-Accept Edits Mode (Aceptar ediciones automáticamente): Cuando ya has revisado el plan de Claude y confías en lo que va a hacer, pulsas Shift + Tab para activar Auto-Accept Edits. En este modo, Claude crea y modifica todos los archivos del plan de principio a fin sin interrumpirte en cada archivo.

3. Ejemplo práctico del flujo "Primero Planificar, Luego Ejecutar"

Así es como se ve una sesión real aplicando este método de dos pasos en Claude Code:


# PASO 1: Pulsas Shift+Tab para activar [Plan Mode] y escribes tu petición:
> Lee @README.md y traza un plan para añadir una vista de Gemini y otra de Claude
  en la barra de navegación superior, con sus respectivos apartados en el sidebar.

# Claude investiga los archivos sin modificar nada y te responde:
  "He leído README.md, constants.json y sidebar.js. Propongo este plan:
   1. Crear carpetas components/gemini y components/claude con common/assets/
   2. Crear los componentes WebComponent (.html y .js) y sus diagramas SVG
   3. Registrar todo en js/components-imports.js y constants.json
   ¿Quieres que proceda con este plan?"

# PASO 2: Pulsas Shift+Tab para pasar a [Auto-Accept Edits] y dices:
> Adelante, ejecuta el plan completo.
Flujo recomendado en dos pasos: acordar primero el diseño en Plan Mode y ejecutarlo después en Auto-Accept Mode.
