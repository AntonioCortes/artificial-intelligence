Claude Web y Desktop: Artifacts, Projects y Estilos

1. Cómo sacar el máximo partido a la interfaz visual de Claude (claude.ai)

Antes incluso de abrir la terminal con Claude Code, muchas personas utilizan Claude desde el navegador web (claude.ai) o desde su aplicación de escritorio para diseñar prototipos, analizar documentos PDF, redactar textos técnicos o aprender a programar. Para dominarlo desde cero, debes conocer sus tres herramientas estrella: Artifacts, Projects y Styles.

2. ¿Qué son los Artifacts (Artefactos) en Claude y cómo funcionan?

En un chat tradicional, si le pides a la IA que programe una calculadora en HTML o un diagrama de flujo, te devuelve un bloque de código que tú tienes que copiar y abrir aparte para ver cómo queda. En cambio, en Claude existe la ventana lateral de Artifacts (Artefactos):

  • Previsualización interactiva en tiempo real: Cuando Claude genera una página HTML/CSS/JS, un componente interactivo en React, un gráfico vectorial SVG o un diagrama Mermaid, la pantalla se divide en dos: a la izquierda sigue tu conversación y a la derecha ves la aplicación o el diagrama funcionando en vivo, pudiendo pulsar botones y probarlo al instante.
  • Versionado automático (Selector de versiones v1, v2, v3...): Si le dices a Claude: "Cambia el color del fondo a azul oscuro y añade un botón de exportar", Claude actualiza el Artefacto creando una nueva versión. En la barra inferior del Artefacto puedes volver atrás a cualquier versión anterior sin perder nada.
  • Ver código, copiar, descargar o publicar: En la esquina superior derecha del Artefacto tienes un interruptor para alternar entre Preview (Vista previa visual) y Code (El código fuente), además de botones para descargarlo como archivo o compartir un enlace interactivo.

3. ¿Qué son los Projects (Proyectos) en Claude?

Si trabajas habitualmente sobre un mismo tema o repositorio en la web de Claude, sería muy tedioso tener que volver a subir tus manuales, el README.md o las guías de estilo cada vez que abres un chat nuevo. Los Projects (Proyectos) resuelven exactamente este problema dividiéndose en dos partes:

Elemento del Proyecto Qué se guarda dentro Ejemplo práctico
1. Project Knowledge (Base de Conocimiento) Archivos PDF, documentos Word, archivos de código, JSONs, READMEs o repositorios conectados de GitHub. Subes el archivo README.md y los CSS de tu plantilla web una sola vez. Todos los chats que abras dentro de ese Proyecto podrán leerlos al instante.
2. Custom Instructions (Instrucciones del Proyecto) Las reglas permanentes de comportamiento, rol y formato para todos los chats de ese proyecto. "Actúa como un experto en WebComponents y Bootstrap 5. Responde siempre en español y usa las clases CSS definidas en el README adjunto."

4. Estilos de Respuesta (Styles): Adapta cómo te habla Claude

Justo debajo del cuadro donde escribes tu mensaje en Claude verás un icono de pincel o selector de Style (Estilo de escritura). Permite cambiar al instante la forma en que Claude redacta sus respuestas sin tener que pedírselo en el prompt:

  • Normal: El estilo equilibrado por defecto de Claude.
  • Concise (Conciso): Respuestas mucho más cortas y directas al grano, ideal cuando tienes prisa y solo quieres el comando o el dato exacto.
  • Explanatory (Explicativo / Didáctico): Ideal para aprender desde cero. Claude desglosa los conceptos con analogías, pasos detallados y contexto educativo.
  • Formal: Redacción profesional y estructurada para informes o correos corporativos.
  • Create & Edit Styles (Crear tu propio Estilo): Puedes subir un texto escrito por ti para que Claude analice tu forma de expresarte y cree un estilo personalizado que imite exactamente tu tono.
