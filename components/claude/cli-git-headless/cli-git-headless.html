Referencia Completa de Terminal (CLI Subcommands y Flags), Tuberías Unix y Git

1. Todos los Subcomandos Directos de claude en la Terminal

Además de abrir el chat interactivo escribiendo simplemente claude, el ejecutable de Claude Code incluye un conjunto completo de subcomandos de administración que puedes lanzar directamente desde tu terminal (Bash, Zsh o PowerShell) sin entrar en una conversación:

Figura 1. Las modalidades de arranque de Claude Code en consola, sus subcomandos y su integración con tuberías Unix y Git.
Subcomando de Terminal Operaciones disponibles Para qué sirve
claude / claude "prompt" Ejecución principal Abre el chat interactivo en tu carpeta actual (o envía directamente la primera instrucción entre comillas).
claude auth ... login, logout, status (con --claudeai, --console, --sso) Inicia sesión en tu cuenta de Anthropic, cierra sesión o comprueba el estado actual de tu autenticación.
claude setup-token Asistente de token de larga duración Genera un token de autenticación de larga duración para usar tu suscripción de Claude en servidores o automatizaciones.
claude mcp ... add, add-json, add-from-claude-desktop, list, get, remove, login, logout, reset-project-choices, serve, xaa Gestiona todos tus servidores MCP desde la terminal (añadir por HTTP/SSE/stdio, importar desde Claude Desktop, listar su estado de salud o iniciar Claude Code como un servidor MCP con serve).
claude plugin ... install, uninstall, enable, disable, update, list, validate Instala, activa, desactiva, actualiza o valida paquetes de plugins de Claude Code en el ámbito de usuario (-s user), proyecto (-s project) o local (-s local).
claude marketplace ... add, list, remove, update Añade, consulta o actualiza catálogos de plugins (marketplaces) desde repositorios Git, URLs o carpetas locales.
claude agents Gestión de sesiones en segundo plano (con --all, --cwd, --json) Lista y administra los agentes y sesiones que están ejecutándose en segundo plano (--bg).
claude auto-mode ... config, defaults, critique, reset Inspecciona las reglas del clasificador de seguridad del modo automático (allow, soft_deny, hard_deny), pide feedback con IA sobre tus reglas o las restaura de fábrica.
claude ultrareview [objetivo] Rama actual, número de PR o rama base (con --post, --json, --timeout) Lanza una revisión exhaustiva de código multi-agente en la nube sobre tu rama o Pull Request e imprime los hallazgos en consola (o los publica en el PR con --post).
claude doctor Diagnóstico de instalación Comprueba la salud de tu instalación de Claude Code y la validez de tus archivos settings.json.
claude install [versión] / claude update stable, latest o versión exacta (con --force) Instala o actualiza la compilación nativa de Claude Code a la última versión disponible.

2. Todas las Banderas (CLI Flags) de Sesión, Entorno de Trabajo y Git Worktrees

Al iniciar claude, puedes añadir cualquiera de estas banderas para controlar qué conversación abrir, en qué carpetas trabajar o si deseas aislar la sesión en un worktree de Git o en la nube:

Bandera (Flag) Qué hace Ejemplo o caso de uso
-c, --continue Reabre automáticamente la última conversación que tuviste en la carpeta actual. Ideal si cerraste la terminal sin querer y quieres retomar donde lo dejaste.
-r [id/texto], --resume [id/texto] Abre un selector interactivo con tus conversaciones pasadas o reanuda directamente una por su ID o nombre. claude -r "refactor-navbar"
--fork-session Al usar --resume o --continue, crea una bifurcación con un nuevo ID de sesión sin sobrescribir la original. Para probar otro enfoque a partir de una conversación previa conservando la original intacta.
-n <nombre>, --name <nombre> Asigna un título visible a la sesión desde el arranque. claude -n "migracion-css"
--session-id <uuid> Fuerza un identificador UUID específico para la conversación. Útil en integraciones automatizadas que llevan registro de sesiones.
--from-pr [número/URL] Reanuda una sesión vinculada a un Pull Request de GitHub o abre el selector de PRs. claude --from-pr 42
-w [nombre], --worktree [nombre] Crea automáticamente un nuevo Git Worktree aislado para esta sesión para no tocar tu copia de trabajo principal. claude -w experimento-sidebar
--tmux / --tmux=classic Crea una sesión o panel de tmux (o panel nativo en iTerm2) para el worktree creado con -w. claude -w feature-login --tmux
--add-dir <rutas...> Concede acceso a carpetas adicionales fuera del directorio actual. claude --add-dir ../backend ../shared
--bg, --background Inicia la sesión en segundo plano y devuelve su ID inmediatamente para gestionarla con claude agents. Para lanzar tareas largas sin bloquear tu consola actual.
--cloud [desc|id|url] Crea una sesión en la nube o se conecta a una existente en claude.ai/code (con --ref o --on-branch). Para delegar tareas a un entorno remoto de Claude en la nube.
--remote-control [nombre] (o --rc) Inicia la sesión local con Remote Control activado para supervisarla desde web o móvil. claude --rc
--teleport [sesión] Trae (teletransporta) una sesión de la nube a tu terminal local. claude --teleport
--desktop Transfiere y abre la sesión directamente en la aplicación Claude Desktop en lugar de la consola. claude -c --desktop
--ide Conecta automáticamente Claude Code al IDE abierto (VS Code / Cursor / JetBrains) al arrancar. claude --ide
--chrome / --no-chrome Activa o desactiva la integración con el navegador Google Chrome en esa sesión. claude --chrome
--prefill <texto> Rellena la caja de texto inicial con tu mensaje pero sin enviarlo hasta que pulses Enter. Útil en lanzadores o atajos personalizados de escritorio.
--rewind-files <id-mensaje> Restaura los archivos al punto de control exacto de un mensaje anterior y sale (requiere --resume). Para revertir cambios desde línea de comandos.

3. Banderas de Modelo, Esfuerzo, Prompts de Sistema, Permisos y Seguridad

Estas opciones te permiten personalizar qué cerebro usa Claude, cómo razona, qué instrucciones de sistema recibe y qué permisos o servidores MCP carga al iniciar:

Bandera (Flag) Qué configura Detalles y valores admitidos
--model <modelo> Modelo principal de la sesión Acepta alias cortos (sonnet, opus, haiku) o el identificador completo del modelo.
--fallback-model <modelos> Modelo de respaldo automático Si el modelo principal está saturado, cambia automáticamente al modelo de respaldo indicado (solo con -p).
--effort <nivel> Nivel de esfuerzo de razonamiento Ajusta la profundidad de pensamiento (low, medium, high, xhigh, max).
--thinking <enabled|disabled> Modo de pensamiento extendido Activa (modo adaptativo) o desactiva los bloques de pensamiento interno del modelo.
--thinking-display <modo> Visualización del pensamiento Controla cómo se muestra el razonamiento en la respuesta (summarized, raw, none).
--advisor <modelo> Modelo consejero (Advisor) Habilita la herramienta de servidor advisor con el modelo indicado (ej. usar Sonnet apoyado por Opus como consejero).
--agent <nombre> / --agents <json> Agente activo o agentes a medida Inicia la sesión con un subagente específico (--agent) o define subagentes personalizados al vuelo mediante un JSON (--agents).
--system-prompt <texto> / --system-prompt-file <ruta> Reemplazar System Prompt Sustituye el prompt de sistema base por tu propio texto o archivo.
--append-system-prompt <texto> / --append-system-prompt-file <ruta> Añadir al System Prompt Conserva todas las capacidades nativas de Claude Code y añade al final tus instrucciones o reglas extra.
--autocompact <auto|tokens> Umbral de auto-compactación Configura a cuántos tokens (entre 100k y 1M, o auto) se compacta automáticamente el contexto.
--permission-mode <modo> Modo de permisos inicial Valores: default, plan, acceptEdits, auto, dontAsk o bypassPermissions.
--plan-mode-required Exigir planificación previa Obliga a pasar por el modo de planificación (plan) antes de permitir cualquier implementación en el código.
--allow-tools <lista> / --disallow-tools <lista> Permitir o prohibir herramientas Pre-autoriza herramientas sin preguntar (ej. "Bash(git diff:*)" "Edit") o las bloquea por completo en la sesión.
--tools <lista> Restringir conjunto de herramientas Especifica exactamente qué herramientas internas de Claude están cargadas ("" para desactivar todas o "default").
--restricted Modo Restringido de alta seguridad Desactiva las herramientas de ejecución de código (Bash) y WebFetch, ignora configuraciones locales y confina los archivos estrictamente al directorio de trabajo.
--safe-mode / --bare Modo Seguro / Modo Mínimo --safe-mode arranca desactivando todas las personalizaciones (CLAUDE.md, skills, plugins, hooks, MCPs). --bare inicia un entorno mínimo ultrarrápido ideal para llamadas desde scripts/SDK.
--mcp-config <json/archivo> / --strict-mcp-config Configuración de servidores MCP Carga servidores MCP desde un archivo JSON específico. Si añades --strict-mcp-config, ignora cualquier otro MCP global o del proyecto.
--plugin-dir <ruta> / --plugin-url <url> Cargar plugins por sesión Carga un plugin desde una carpeta o archivo .zip local o remoto únicamente durante esta sesión.
--settings <archivo/json> / --setting-sources <fuentes> Ajustes personalizados Carga un settings.json adicional o elige qué niveles cargar (user,project,local).
--disable-slash-commands Desactivar skills y comandos Deshabilita la carga de todos los skills y comandos personalizados / durante la sesión.

4. Banderas de Modo No Interactivo (-p / Headless), Automatización y Depuración

Cuando utilizas claude -p (o --print) en scripts, pipelines CI/CD o tuberías de consola, dispones de banderas específicas para controlar el formato de salida, esquemas JSON, límites de gasto y depuración:

Bandera (Flag) Qué hace Valores o ejemplo
-p, --print Ejecuta la instrucción en modo no interactivo, imprime la respuesta en la salida estándar y termina. claude -p "Explica main.js"
--output-format <formato> Define el formato de salida en modo -p. text (por defecto), json (objeto con respuesta y metadatos) o stream-json (eventos en tiempo real).
--input-format <formato> Define el formato de los datos que entran por tubería (stdin). text (por defecto) o stream-json.
--json-schema <esquema> Obliga a que la salida final de Claude cumpla estrictamente un esquema JSON Schema validado. claude -p "Extrae rutas" --output-format json --json-schema '{"type":"object",...}'
--max-turns <n> Limita el número máximo de pasos/turnos autónomos que puede dar el agente en modo -p. claude -p "Arregla los tests" --max-turns 5
--max-budget-usd <importe> / --task-budget <tokens> Fija un tope máximo de gasto en dólares o un presupuesto de tokens para la ejecución en modo -p. claude -p "Analiza logs" --max-budget-usd 0.50
--no-session-persistence Evita guardar la sesión en disco cuando se ejecuta con -p. Ideal para llamadas efímeras desde scripts.
--include-partial-messages / --include-hook-events Incluye fragmentos de texto en streaming y eventos de hooks al usar --output-format=stream-json. Para construir interfaces personalizadas sobre Claude CLI.
-d [filtro], --debug [filtro] / --debug-file <ruta> Activa el modo de depuración (pudiendo filtrar por categorías como --debug=hooks,mcp) o vuelca el registro en un archivo. claude --debug=mcp
--verbose / -v, --version / -h, --help Activa trazas detalladas (--verbose), muestra la versión instalada (-v) o la ayuda (-h). claude --version

5. Usar Claude con Tuberías de Terminal (Unix Pipes |) y Git

Combinando la opción -p con el símbolo de tubería | de Linux/macOS/WSL, puedes conectar la salida de cualquier comando directamente al cerebro de Claude:


# Ejemplo 1: Enviar un archivo de registro de errores (log) para que te explique por qué falla
cat errores-servidor.log | claude -p "Explica cuál es la causa raíz de este error y cómo arreglarlo"

# Ejemplo 2: Revisar los cambios pendientes de Git antes de subirlos
git diff | claude -p "Revisa si hay algún error de sintaxis o archivo olvidado en estos cambios"

# Ejemplo 3: Pedir salida JSON validada contra un esquema JSON Schema
claude -p "Lista los nombres de las vistas de constants.json" --output-format json

# Ejemplo 4: Trabajar en una funcionalidad nueva dentro de un Git Worktree aislado
claude -w nueva-seccion-claude
Ejemplos de uso del modo headless (-p) con tuberías Unix y aislamiento con Git Worktrees (-w).

Además, dentro del chat interactivo, Claude Code puede encargarse de todo el flujo de Git por ti en lenguaje natural (o mediante el comando rápido /commit-push-pr): analizar qué archivos han cambiado con git status y git diff, redactar mensajes de commit claros, resolver conflictos de merge línea por línea o abrir Pull Requests usando gh.
